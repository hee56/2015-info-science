    📖 Chapter 03: 스택 - 뒤로 가기 버튼의 비밀¶

    Part 1 | [1권] 자료구조의 기초 - 순차 자료구조와 연결 자료구조

    🎯 이 장에서 배우는 것¶

    • 스택의 LIFO(후입선출) 원리를 이해하고 실생활 사례와 연결할 수 있다
    • 파이썬 리스트를 활용하여 스택의 push·pop·peek·is_empty 연산을 구현할 수 있다
    • 스택을 활용하여 괄호 검사 문제를 해결할 수 있다
    • 스택을 활용하여 문자열 뒤집기를 구현할 수 있다

    💡 왜 이걸 배우나요?¶

    지금 여러분이 보고 있는 웹 브라우저에는 ← 뒤로 가기 버튼이 있습니다. 이 버튼을 누르면 가장 최근에 방문한 페이지로 돌아갑니다. 두 번째로 방문한 페이지가 아니라, 세 번째도 아니라, 항상 마지막에 본 페이지로 돌아가죠.

    이것이 바로 스택(Stack) 의 원리입니다.

    스택은 프로그래밍에서 놀라울 정도로 자주 등장합니다.

    • 🌐 브라우저의 뒤로 가기/앞으로 가기
    • ↩️ 워드프로세서의 Ctrl+Z (실행 취소)
    • 🧮 계산기의 수식 처리
    • 🐍 파이썬 함수 호출 구조 (콜 스택)

    이 모든 것의 기반이 되는 자료구조, 스택을 지금부터 직접 만들어 봅시다!

    📚 핵심 개념¶

    개념 1: LIFO — 나중에 들어온 것이 먼저 나간다 🍽️¶

    비유로 시작해 볼까요?

    구내식당에서 접시를 떠올려 보세요. 깨끗이 씻은 접시를 한 장씩 쌓습니다. 밥을 받으러 온 사람은 맨 위의 접시부터 가져갑니다. 가장 먼저 쌓았던 맨 아래 접시는 가장 마지막에 꺼내게 됩니다.

    정확한 정의

    📌 스택(Stack) 이란, 데이터를 한쪽 끝(top)에서만 넣고 빼는 자료구조입니다. LIFO(Last In, First Out) — "마지막에 들어온 것이 처음으로 나간다"는 원칙을 따릅니다.

    예시로 확인

    접시를 A → B → C 순서로 쌓았다면, 꺼낼 때는 C → B → A 순서가 됩니다.

    graph LR subgraph 넣는 순서 direction LR A1["A 넣기"] --> B1["B 넣기"] --> C1["C 넣기"] end subgraph 빼는 순서 direction LR C2["C 빼기"] --> B2["B 빼기"] --> A2["A 빼기"] end

    💡 알아보기: 2장에서 배운 리스트(배열)는 아무 위치에서나 데이터를 넣고 뺄 수 있었습니다. 스택은 의도적으로 한쪽 끝(top)에서만 접근하도록 제한한 구조입니다. 제한을 두었기 때문에 오히려 특정 문제를 더 간결하고 안전하게 해결할 수 있습니다.

    개념 2: 스택의 4가지 핵심 연산 🛠️¶

    비유로 시작

    접시 쌓기를 계속 떠올려 봅시다.

    • 접시를 위에 올린다 → push
    • 맨 위 접시를 꺼낸다 → pop
    • 맨 위 접시를 꺼내지 않고 살짝 본다 → peek
    • 접시가 하나도 없는지 확인한다 → is_empty

    정확한 정의

    • push(item) — 스택의 맨 위(top)에 데이터를 추가
    • pop() — 스택의 맨 위 데이터를 제거하고 반환
    • peek() — 스택의 맨 위 데이터를 제거하지 않고 확인
    • is_empty() — 스택이 비어 있으면 True, 아니면 False

    예시로 확인 — 연산 흐름 추적

    graph TD S0["빈 스택<br/>top → 없음"] -->|"push('A')"| S1["top → A"] S1 -->|"push('B')"| S2["top → B<br/>A"] S2 -->|"push('C')"| S3["top → C<br/>B<br/>A"] S3 -->|"pop() → C"| S4["top → B<br/>A"] S4 -->|"peek() → B"| S5["top → B<br/>A<br/>(변화 없음)"]

    🔑 핵심 포인트: pop()은 데이터를 꺼내면서 삭제하고, peek()은 데이터를 보기만 합니다.

    개념 3: 파이썬 리스트로 스택 만들기 🐍¶

    비유로 시작

    파이썬의 리스트(list)는 이미 append()와 pop()이라는 메서드를 갖고 있습니다. 리스트의 오른쪽 끝을 top으로 삼으면, 그 자체가 스택처럼 동작합니다!

    정확한 정의

    • 리스트.append(item) → push 역할 (맨 뒤에 추가)
    • 리스트.pop() → pop 역할 (맨 뒤 요소 제거 후 반환)
    • 리스트[-1] → peek 역할 (맨 뒤 요소 확인)
    • len(리스트) == 0 → is_empty 역할

    예시로 확인

    stack = []              # 빈 스택 생성
stack.append('A')       # push 'A'  → ['A']
stack.append('B')       # push 'B'  → ['A', 'B']
stack.append('C')       # push 'C'  → ['A', 'B', 'C']

top = stack.pop()       # pop → 'C' 반환, 스택 → ['A', 'B']
print(top)              # 출력: C

print(stack[-1])        # peek → 출력: B
print(len(stack) == 0)  # is_empty → 출력: False

    💡 생각해보기: append()와 pop()은 리스트의 맨 뒤에서 동작하므로 시간 복잡도가 O(1) 입니다. 즉, 리스트의 크기가 커져도 항상 빠르게 실행됩니다. 스택으로 쓰기에 딱 적합하죠!

    개념 4: 스택의 대표 활용 — 괄호 검사 🔍¶

    비유로 시작

    코딩을 하다 보면 (, ), {, }, [, ] 같은 괄호를 많이 씁니다. 괄호가 올바르게 짝이 맞는지 확인하는 것은 컴파일러(번역기)가 가장 먼저 하는 일 중 하나입니다.

    원리: 왜 스택인가?

    여는 괄호 (를 만나면 스택에 push 합니다. 닫는 괄호 )를 만나면 스택에서 pop 하여 짝이 맞는지 확인합니다. 모든 문자를 처리한 뒤 스택이 비어 있으면 괄호가 올바른 것입니다.

    flowchart TD Start(["문자열의 각 문자를 순회"]) --> IsOpen{"여는 괄호?<br/>( [ {"} IsOpen -- 예 --> Push["스택에 push"] Push --> Next["다음 문자로"] IsOpen -- 아니오 --> IsClose{"닫는 괄호?<br/>) ] }"} IsClose -- 아니오 --> Next IsClose -- 예 --> Empty{"스택이<br/>비어있나?"} Empty -- 예 --> Fail(["❌ 짝 없음 — 실패"]) Empty -- 아니오 --> Pop["스택에서 pop"] Pop --> Match{"짝이<br/>맞나?"} Match -- 예 --> Next Match -- 아니오 --> Fail2(["❌ 짝 불일치 — 실패"]) Next --> Done{"모든 문자<br/>처리 완료?"} Done -- 아니오 --> IsOpen Done -- 예 --> FinalCheck{"스택이<br/>비어있나?"} FinalCheck -- 예 --> Success(["✅ 괄호 올바름"]) FinalCheck -- 아니오 --> Fail3(["❌ 여는 괄호 남음 — 실패"])

    예시로 확인

    문자열 "(A + B) * [C - {D / E}]" 를 검사한다고 합시다.

    • ( → push → 스택: [(]
    • ) → pop하여 (과 짝 확인 ✅ → 스택: []
    • [ → push → 스택: [[]
    • { → push → 스택: [[,{]
    • } → pop하여 {과 짝 확인 ✅ → 스택: [[]
    • ] → pop하여 [과 짝 확인 ✅ → 스택: []
    • 스택이 비어 있으므로 → ✅ 올바른 괄호!

    🔨 따라하기¶

    Step 1: 기본 스택 함수 만들기¶

    하나의 리스트를 스택으로 사용하고, 4가지 연산을 함수로 만들어 봅시다.

    # 스택 생성
def create_stack():
    return []

# push: 맨 위에 데이터 추가
def push(stack, item):
    stack.append(item)
    print(f"push: {item} → 스택 상태: {stack}")

# pop: 맨 위 데이터 꺼내기
def pop(stack):
    if is_empty(stack):
        print("스택이 비어 있습니다!")
        return None
    item = stack.pop()
    print(f"pop: {item} → 스택 상태: {stack}")
    return item

# peek: 맨 위 데이터 확인 (꺼내지 않음)
def peek(stack):
    if is_empty(stack):
        print("스택이 비어 있습니다!")
        return None
    return stack[-1]

# is_empty: 비어있는지 확인
def is_empty(stack):
    return len(stack) == 0

    Step 2: 스택 동작 테스트하기¶

    위 함수들을 실제로 호출해서 동작을 확인합니다.

    # 스택 생성 및 테스트
my_stack = create_stack()

push(my_stack, '가')
push(my_stack, '나')
push(my_stack, '다')

print(f"peek: {peek(my_stack)}")  # 다

pop(my_stack)   # 다 꺼냄
pop(my_stack)   # 나 꺼냄

print(f"peek: {peek(my_stack)}")  # 가
print(f"비어있나? {is_empty(my_stack)}")  # False

pop(my_stack)   # 가 꺼냄
print(f"비어있나? {is_empty(my_stack)}")  # True
pop(my_stack)   # 비어있는 스택에서 pop 시도

    예상 출력:

    push: 가 → 스택 상태: ['가']
push: 나 → 스택 상태: ['가', '나']
push: 다 → 스택 상태: ['가', '나', '다']
peek: 다
pop: 다 → 스택 상태: ['가', '나']
pop: 나 → 스택 상태: ['가']
peek: 가
비어있나? False
pop: 가 → 스택 상태: []
비어있나? True
스택이 비어 있습니다!

    Step 3: 괄호 검사 프로그램 만들기¶

    핵심 개념 4에서 배운 알고리즘을 코드로 옮겨봅시다.

    def check_brackets(expression):
    stack = []
    # 여는 괄호와 닫는 괄호의 짝을 딕셔너리로 정의
    pairs = {')': '(', ']': '[', '}': '{'}

    for char in expression:
        # 여는 괄호이면 push
        if char in '([{':
            stack.append(char)
        # 닫는 괄호이면
        elif char in ')]}':
            if len(stack) == 0:
                return False   # 짝이 없음
            top = stack.pop()
            if top != pairs[char]:
                return False   # 짝이 맞지 않음

    # 모든 문자 처리 후 스택이 비어있어야 성공
    return len(stack) == 0

    Step 4: 괄호 검사 테스트하기¶

    test_cases = [
    "(A + B) * [C - {D / E}]",   # 올바름
    "((A + B)",                    # 여는 괄호 남음
    "(A + B)]",                    # 짝 불일치
    "{[()]}",                      # 올바름
    ")(",                          # 닫는 괄호가 먼저
]

for expr in test_cases:
    result = "✅ 올바름" if check_brackets(expr) else "❌ 오류"
    print(f"{expr:30s} → {result}")

    예상 출력:

    (A + B) * [C - {D / E}]       → ✅ 올바름
((A + B)                       → ❌ 오류
(A + B)]                       → ❌ 오류
{[()]}                         → ✅ 올바름
)(                             → ❌ 오류

    Step 5: 문자열 뒤집기¶

    스택의 LIFO 성질을 이용하면 문자열을 간단히 뒤집을 수 있습니다.

    def reverse_string(text):
    stack = []

    # 모든 문자를 스택에 push
    for char in text:
        stack.append(char)

    # 스택에서 하나씩 pop하여 새 문자열 구성
    result = ""
    while len(stack) > 0:
        result += stack.pop()

    return result

# 테스트
print(reverse_string("Hello"))    # olleH
print(reverse_string("스택"))      # 택스
print(reverse_string("abcde"))    # edcba

    💡 생각해보기: 파이썬에는 text[::-1]이라는 간편한 슬라이싱이 있습니다. 하지만 이 실습의 목적은 스택의 LIFO 원리를 직접 체험하는 것입니다. 원리를 이해한 뒤에 편리한 문법을 사용하는 것이 올바른 순서입니다!

    Step 6: 브라우저 뒤로 가기 시뮬레이션¶

    도입부에서 이야기한 브라우저의 뒤로 가기를 스택으로 구현해 봅시다.

    def browser_simulation():
    back_stack = []      # 뒤로 가기 스택
    current_page = None  # 현재 페이지

    def visit(url):
        nonlocal current_page
        if current_page is not None:
            back_stack.append(current_page)  # 현재 페이지를 스택에 push
        current_page = url
        print(f"  🌐 방문: {current_page}")

    def go_back():
        nonlocal current_page
        if len(back_stack) == 0:
            print("  ⚠️ 더 이상 뒤로 갈 수 없습니다!")
            return
        current_page = back_stack.pop()  # 스택에서 pop
        print(f"  ← 뒤로 가기: {current_page}")

    # 시뮬레이션 시작
    print("=== 브라우저 시뮬레이션 ===")
    visit("google.com")
    visit("youtube.com")
    visit("github.com")

    go_back()  # github → youtube
    go_back()  # youtube → google
    go_back()  # 더 이상 못 감

def create_stack():
    return []

def push(stack, item):
    stack.append(item)

def pop(stack):
    if is_empty(stack):
        return None
    return stack.pop()

def peek(stack):
    if is_empty(stack):
        return None
    return stack[-1]

def is_empty(stack):
    return len(stack) == 0


# ===== 괄호 검사 =====
def check_brackets(expression):
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}

    for char in expression:
        if char in '([{':
            stack.append(char)
        elif char in ')]}':
            if len(stack) == 0:
                return False
            if stack.pop() != pairs[char]:
                return False

    return len(stack) == 0


# ===== 문자열 뒤집기 =====
def reverse_string(text):
    stack = []
    for char in text:
        stack.append(char)

    result = ""
    while len(stack) > 0:
        result += stack.pop()
    return result

    ⚠️ 자주 하는 실수¶

    실수 1: 빈 스택에서 pop 하기 🚨

    stack = []
stack.pop()  # IndexError: pop from empty list

    pop() 전에 반드시 스택이 비어 있는지 확인해야 합니다. 우리가 만든 함수에서 is_empty() 검사를 넣은 이유입니다.

    실수 2: peek과 pop 혼동하기 🔄

    • peek은 맨 위 요소를 보기만 합니다 (스택 변화 없음)
    • pop은 맨 위 요소를 꺼냅니다 (스택에서 사라짐)

    괄호 검사에서 짝만 확인하고 싶으면 peek, 실제로 제거하려면 pop을 사용해야 합니다. 잘못 쓰면 스택에 데이터가 남거나 사라져서 결과가 틀립니다.

    실수 3: 리스트의 앞쪽(인덱스 0)을 top으로 착각하기 🔢

    # ❌ 잘못된 방법 — 느리고 비효율적!
stack.insert(0, item)   # push를 앞쪽에 하면 O(n)
stack.pop(0)             # pop도 앞쪽에서 하면 O(n)

# ✅ 올바른 방법 — 빠르고 효율적!
stack.append(item)       # push를 뒤쪽에 → O(1)
stack.pop()              # pop도 뒤쪽에서 → O(1)

    리스트의 오른쪽 끝이 top이라는 약속을 기억하세요!

    문자열 "[{()}](" 에 대해 괄호 검사를 손으로 추적해 보세요.

    정답 보기 - `[` → push → 스택: `[`[`]` - `{` → push → 스택: `[`[`, `{`]` - `(` → push → 스택: `[`[`, `{`, `(`]` - `)` → pop `(` ↔ `)` ✅ → 스택: `[`[`, `{`]` - `}` → pop `{` ↔ `}` ✅ → 스택: `[`[`]` - `]` → pop `[` ↔ `]` ✅ → 스택: `[]` - `(` → push → 스택: `[`(`]` - 순회 종료, 스택이 비어있지 않음 → **❌ 오류!**

    응용 문제 — 스택 두 개로 큐 흉내내기 🤔

    스택 두 개(stack_in, stack_out)를 사용하면 FIFO(선입선출) 방식, 즉 큐(Queue)처럼 동작하게 만들 수 있습니다. 어떻게 하면 될까요? 힌트: stack_in에서 모든 데이터를 pop하여 stack_out에 push하면 순서가 뒤집힙니다.

    정답 보기 
    stack_in = []
stack_out = []

def enqueue(item):
    stack_in.append(item)

def dequeue():
    if len(stack_out) == 0:
        # stack_in의 모든 요소를 stack_out으로 옮기기
        while len(stack_in) > 0:
            stack_out.append(stack_in.pop())
    if len(stack_out) == 0:
        return None
    return stack_out.pop()

# 테스트
enqueue('A')
enqueue('B')
enqueue('C')
print(dequeue())  # A (먼저 넣은 것이 먼저 나옴!)
print(dequeue())  # B
