    챕터 9: 히프 - 최댓값과 최솟값을 빠르게 꺼내는 마법¶

    Part 2 | [1권] 비선형 자료구조 - 트리와 히프

    🎯 이 장에서 배우는 것¶

    • 히프의 두 가지 조건(완전 이진 트리 + 히프 속성)을 설명할 수 있다
    • 리스트 인덱스를 이용해 부모·자식 관계를 계산할 수 있다
    • 삽입(bubble up)과 삭제(bubble down) 과정을 단계별로 추적할 수 있다
    • Python의 heapq 모듈을 활용하여 히프를 실전에서 사용할 수 있다

    💡 왜 이걸 배우나요?¶

    학교에서 전교생 500명의 시험 점수 중 상위 5명을 빠르게 뽑아야 한다고 상상해 보세요.

    가장 단순한 방법은 전체를 정렬한 뒤 위에서 5명을 고르는 것입니다. 하지만 점수가 실시간으로 계속 추가된다면? 매번 전체를 다시 정렬하는 건 너무 느립니다.

    이럴 때 필요한 자료구조가 바로 히프(Heap) 입니다.

    🧠 생각해보기: 히프를 사용하면 "가장 큰 값" 또는 "가장 작은 값"을 O(log n) 만에 꺼낼 수 있습니다. 500명에서 가장 높은 점수를 꺼내는 데 고작 9번의 비교만 하면 됩니다!

    📚 핵심 개념¶

    개념 1: 히프란 무엇인가?¶

    🎪 비유로 시작

    놀이공원 VIP 대기열을 떠올려 보세요. 일반 줄(큐)은 먼저 온 사람이 먼저 타지만, VIP 대기열은 등급이 높은 사람이 항상 맨 앞에 섭니다. 새 사람이 오면 등급에 맞는 위치로 쏙 들어가고, 맨 앞 사람이 나가면 나머지가 자동으로 재배치됩니다.

    히프가 바로 이 "우선순위 대기열" 의 내부 엔진입니다.

    📖 정확한 정의

    히프는 다음 두 가지 조건을 동시에 만족하는 트리입니다.

    • 조건 ①: 완전 이진 트리 — 위에서 아래로, 왼쪽에서 오른쪽으로 빈틈없이 노드가 채워져 있다
    • 조건 ②: 히프 속성 — 부모 노드의 값이 자식 노드의 값보다 항상 크거나 같다(최대 히프) 또는 작거나 같다(최소 히프)

    🔍 예시로 확인

    graph TB A["90"] --> B["75"] A --> C["80"] B --> D["30"] B --> E["50"] C --> F["60"] C --> G["40"] style A fill:#ff6b6b,color:#fff,stroke:#ff6b6b style B fill:#ffa07a,color:#fff,stroke:#ffa07a style C fill:#ffa07a,color:#fff,stroke:#ffa07a

    위 트리는 최대 히프입니다. 루트(90)가 가장 크고, 모든 부모가 자식보다 크거나 같습니다.

    📌 알아보기: 최대 히프에서는 루트가 항상 최댓값, 최소 히프에서는 루트가 항상 최솟값입니다. "꼭대기만 보면 답을 안다!" — 이것이 히프의 마법입니다.

    개념 2: 리스트로 히프 표현하기¶

    🎪 비유로 시작

    아파트 호수를 떠올려 보세요. 101호, 102호, 201호, 202호… 번호만으로 몇 층 몇 호인지 알 수 있죠? 히프도 마찬가지로 인덱스 번호만으로 부모와 자식 관계를 알 수 있습니다.

    📖 정확한 정의

    완전 이진 트리는 리스트에 레벨 순서(위→아래, 왼→오) 로 저장할 수 있습니다.

    인덱스 i에 있는 노드의 관계식 (0부터 시작):

    • 부모: (i - 1) // 2
    • 왼쪽 자식: 2 * i + 1
    • 오른쪽 자식: 2 * i + 2

    🔍 예시로 확인

    위의 최대 히프를 리스트로 표현하면:

    인덱스:  0    1    2    3    4    5    6
  값 : [90,  75,  80,  30,  50,  60,  40]
    • 인덱스 1(값 75)의 부모 → (1-1)//2 = 0 → 값 90 ✅
    • 인덱스 2(값 80)의 왼쪽 자식 → 2*2+1 = 5 → 값 60 ✅
    • 인덱스 2(값 80)의 오른쪽 자식 → 2*2+2 = 6 → 값 40 ✅

    💡 정리하기: 리스트 하나로 트리 전체를 표현할 수 있으므로, 별도의 노드 클래스나 포인터가 필요 없습니다. 이것이 히프가 실무에서 사랑받는 이유 중 하나입니다.

    개념 3: 삽입 — 위로 올라가기 (Bubble Up)¶

    🎪 비유로 시작

    회사 신입사원이 입사했는데 능력이 뛰어나면 어떻게 될까요? 먼저 맨 아래(말단)에 배치된 후, 능력에 맞게 한 단계씩 승진합니다. 히프 삽입도 똑같습니다!

    📖 정확한 정의 — 삽입 알고리즘

    1. 새 원소를 리스트의 맨 끝에 추가한다 (완전 이진 트리 유지)
    2. 부모와 비교하여 히프 속성을 위반하면 부모와 교환한다
    3. 히프 속성이 만족되거나 루트에 도달할 때까지 반복한다

    🔍 예시로 확인 — 값 85를 삽입

    현재 히프: [90, 75, 80, 30, 50, 60, 40]

    graph TB subgraph Step1["Step 1: 맨 끝에 추가"] A1["90"]-->B1["75"] A1-->C1["80"] B1-->D1["30"] B1-->E1["50"] C1-->F1["60"] C1-->G1["40"] D1-->H1["🆕 85"] style H1 fill:#4ecdc4,color:#fff,stroke:#4ecdc4 end
    • Step 1: 85를 인덱스 7에 추가 → [90, 75, 80, 30, 50, 60, 40, 85]
    • Step 2: 부모는 인덱스 3(값 30). 85 > 30 → 교환! → [90, 75, 80, 85, 50, 60, 40, 30]
    • Step 3: 새 위치 인덱스 3의 부모는 인덱스 1(값 75). 85 > 75 → 교환! → [90, 85, 80, 75, 50, 60, 40, 30]
    • Step 4: 새 위치 인덱스 1의 부모는 인덱스 0(값 90). 85 < 90 → 멈춤!
    graph TB subgraph Result["최종 결과"] A2["90"]-->B2["✨ 85"] A2-->C2["80"] B2-->D2["75"] B2-->E2["50"] C2-->F2["60"] C2-->G2["40"] D2-->H2["30"] style B2 fill:#4ecdc4,color:#fff,stroke:#4ecdc4 end

    개념 4: 삭제 — 아래로 내려가기 (Bubble Down)¶

    🎪 비유로 시작

    반장이 전학을 갔습니다. 빈 자리에 아무나 임시로 앉힌 뒤, 능력 순으로 한 단계씩 강등시켜서 올바른 위치를 찾는 것과 같습니다.

    📖 정확한 정의 — 삭제 알고리즘 (루트 삭제)

    1. 루트 값(최댓값)을 꺼낸다
    2. 리스트의 맨 마지막 원소를 루트 자리로 옮긴다
    3. 자식 중 더 큰 자식과 비교하여 히프 속성을 위반하면 교환한다
    4. 히프 속성이 만족되거나 리프에 도달할 때까지 반복한다

    🔍 예시로 확인 — 루트(90) 삭제

    현재 히프: [90, 85, 80, 75, 50, 60, 40, 30]

    • Step 1: 루트 90을 꺼내고, 맨 끝 30을 루트로 → [30, 85, 80, 75, 50, 60, 40]
    • Step 2: 자식은 85, 80. 더 큰 쪽은 85. 30 < 85 → 교환! → [85, 30, 80, 75, 50, 60, 40]
    • Step 3: 자식은 75, 50. 더 큰 쪽은 75. 30 < 75 → 교환! → [85, 75, 80, 30, 50, 60, 40]
    • Step 4: 인덱스 3의 자식 없음(리프) → 멈춤!
    graph TB subgraph Final["삭제 후 최종 결과"] A3["85"]-->B3["75"] A3-->C3["80"] B3-->D3["30"] B3-->E3["50"] C3-->F3["60"] C3-->G3["40"] end

    📌 알아보기: 삽입과 삭제 모두 트리의 높이만큼만 이동하므로 시간 복잡도는 O(log n) 입니다. n이 1,000,000이어도 약 20번의 비교면 충분합니다!

    🔨 따라하기¶

    직접 코드를 작성하며 최대 히프를 만들어 봅시다!

    Step 1: 히프 클래스의 뼈대 만들기¶

    class MaxHeap:
    def __init__(self):
        self.heap = []

    def __len__(self):
        return len(self.heap)

    def __str__(self):
        return str(self.heap)

    Step 2: 삽입 — bubble_up 구현하기¶

        def push(self, val):
        self.heap.append(val)          # 맨 끝에 추가
        self._bubble_up(len(self.heap) - 1)

    def _bubble_up(self, idx):
        while idx > 0:
            parent = (idx - 1) // 2
            if self.heap[idx] > self.heap[parent]:
                self.heap[idx], self.heap[parent] = self.heap[parent], self.heap[idx]
                idx = parent
            else:
                break

    Step 3: 삭제 — bubble_down 구현하기¶

        def pop(self):
        if len(self.heap) == 0:
            return None
        if len(self.heap) == 1:
            return self.heap.pop()

        root = self.heap[0]
        self.heap[0] = self.heap.pop()  # 마지막 원소를 루트로
        self._bubble_down(0)
        return root

    def _bubble_down(self, idx):
        size = len(self.heap)
        while True:
            left = 2 * idx + 1
            right = 2 * idx + 2
            largest = idx

            if left < size and self.heap[left] > self.heap[largest]:
                largest = left
            if right < size and self.heap[right] > self.heap[largest]:
                largest = right

            if largest != idx:
                self.heap[idx], self.heap[largest] = self.heap[largest], self.heap[idx]
                idx = largest
            else:
                break

    Step 4: 실행해보기¶

    h = MaxHeap()
for val in [30, 50, 75, 60, 80, 40, 90]:
    h.push(val)
    print(f"{val} 삽입 후: {h}")

print(f"\n최댓값 꺼내기: {h.pop()}")
print(f"꺼낸 후 히프: {h}")
print(f"다시 꺼내기: {h.pop()}")
print(f"꺼낸 후 히프: {h}")

    Step 5: heapq 모듈로 간단하게 (최소 히프)¶

    Python의 heapq는 최소 히프를 제공합니다.

    import heapq

scores = []
for val in [30, 50, 75, 60, 80, 40, 90]:
    heapq.heappush(scores, val)
    print(f"{val} 삽입 후: {scores}")

print(f"\n최솟값 꺼내기: {heapq.heappop(scores)}")
print(f"꺼낸 후: {scores}")

    Step 6: heapq로 최대 히프 흉내내기¶

    heapq는 최소 히프만 지원하므로, 부호를 뒤집는 트릭을 사용합니다.

    import heapq

max_heap = []
for val in [30, 50, 75, 60, 80, 40, 90]:
    heapq.heappush(max_heap, -val)   # 음수로 넣기

# 꺼낼 때 다시 부호를 뒤집으면 최댓값!
print(f"최댓값: {-heapq.heappop(max_heap)}")  # 90
print(f"그 다음: {-heapq.heappop(max_heap)}")  # 80

    📝 전체 코드¶

    class MaxHeap:
    """리스트 기반 최대 히프 구현"""

    def __init__(self):
        self.heap = []

    def __len__(self):
        return len(self.heap)

    def __str__(self):
        return str(self.heap)

    def push(self, val):
        """새 원소를 삽입한다"""
        self.heap.append(val)
        self._bubble_up(len(self.heap) - 1)

    def pop(self):
        """최댓값을 꺼내어 반환한다"""
        if len(self.heap) == 0:
            return None
        if len(self.heap) == 1:
            return self.heap.pop()

        root = self.heap[0]
        self.heap[0] = self.heap.pop()
        self._bubble_down(0)
        return root

    def peek(self):
        """최댓값을 확인만 한다 (제거하지 않음)"""
        return self.heap[0] if self.heap else None

    def _bubble_up(self, idx):
        while idx > 0:
            parent = (idx - 1) // 2
            if self.heap[idx] > self.heap[parent]:
                self.heap[idx], self.heap[parent] = self.heap[parent], self.heap[idx]
                idx = parent
            else:
                break

    def _bubble_down(self, idx):
        size = len(self.heap)
        while True:
            left = 2 * idx + 1
            right = 2 * idx + 2
            largest = idx

            if left < size and self.heap[left] > self.heap[largest]:
                largest = left
            if right < size and self.heap[right] > self.heap[largest]:
                largest = right

            if largest != idx:
                self.heap[idx], self.heap[largest] = self.heap[largest], self.heap[idx]
                idx = largest
            else:
                break


# === 테스트 ===
if __name__ == "__main__":
    h = MaxHeap()
    data = [30, 50, 75, 60, 80, 40, 90]

    print("=== 삽입 과정 ===")
    for val in data:
        h.push(val)
        print(f"  {val:>2} 삽입 → {h}")

    print(f"\n=== 삭제 과정 ===")
    while len(h) > 0:
        val = h.pop()
        print(f"  꺼낸 값: {val:>2} | 남은 히프: {h}")

    ⚠️ 자주 하는 실수¶

    실수 1: 인덱스 시작을 1로 착각 🔢

    교과서에 따라 인덱스를 1부터 시작하는 경우가 있습니다. 이 경우 자식은 2i, 2i+1이고, 부모는 i//2입니다. Python 리스트는 0부터 시작하므로 공식이 달라집니다. 자신이 사용하는 공식이 어떤 기준인지 반드시 확인하세요!

    실수 2: bubble_down에서 자식 하나만 비교 ⚖️

    자식이 두 개일 때 둘 중 더 큰 쪽(최대 히프)과 비교해야 합니다. 왼쪽 자식만 비교하면 히프 속성이 깨질 수 있습니다.

    # ❌ 잘못된 코드
if left < size and self.heap[left] > self.heap[idx]:
    self.heap[idx], self.heap[left] = self.heap[left], self.heap[idx]

    📖 핵심 요약 - 히프 = 완전 이진 트리 + 히프 속성(부모 ≥ 자식 또는 부모 ≤ 자식) - 리스트 인덱스로 부모·자식 관계를 계산: 부모 (i-1)//2, 자식 2i+1, 2i+2 - 삽입은 맨 끝 추가 → bubble up, 삭제는 루트 제거 → 마지막을 루트로 → bubble down - 삽입·삭제 모두 O(log n), 루트 확인은 O(1) - Python heapq는 최소 히프, 음수 트릭으로 최대 히프 구현 가능
