    챕터 17: 히프 정렬과 해시 탐색 - 자료구조가 만드는 알고리즘¶

    🎯 이 장에서 배우는 것¶

    • 히프 자료구조를 활용해 정렬하는 히프 정렬의 원리를 설명할 수 있다
    • 해시 함수와 해시 테이블의 개념을 이해하고 동작 방식을 설명할 수 있다
    • 파이썬 딕셔너리가 해시 테이블 기반임을 이해하고 활용할 수 있다
    • 자료구조 선택이 알고리즘 효율성을 결정한다는 핵심 원리를 체득할 수 있다

    💡 왜 이걸 배우나요?¶

    9차시에서 우리는 히프(Heap)라는 자료구조를 배웠습니다. 그때는 "가장 큰(또는 작은) 값을 빠르게 꺼내는 구조"로 배웠죠. 그런데 잠깐 — 가장 작은 값을 계속 꺼내면 어떤 일이 벌어질까요?

    가장 작은 것 → 그다음 작은 것 → 그다음… 🤔

    맞습니다! 정렬이 됩니다. 자료구조 하나를 알면, 그것이 곧 알고리즘이 될 수 있다는 놀라운 사실을 발견하게 됩니다.

    이어서 해시(Hash)를 배웁니다. 도서관에서 책을 찾을 때, 처음부터 끝까지 훑는 사람은 없겠죠? 책의 분류번호를 보고 바로 그 선반으로 갑니다. 해시도 마찬가지입니다. 데이터를 특정 "주소"로 변환해서 단번에 찾아가는 기술입니다.

    이번 장의 핵심 메시지는 하나입니다:

    🔑 "어떤 자료구조를 선택하느냐가 알고리즘의 속도를 결정한다."

    📚 핵심 개념¶

    개념 1: 히프 정렬 — 히프에서 하나씩 꺼내면 정렬 완성¶

    🎪 비유로 시작

    놀이공원의 "키 순서대로 타기" 줄을 떠올려 보세요. 키가 가장 작은 사람이 항상 맨 앞에 서는 특별한 줄(최소 히프)이 있다고 합시다. 이 줄에서 한 명씩 앞으로 내보내면? 키 순서대로 나오게 됩니다!

    📖 정확한 정의

    히프 정렬(Heap Sort)은 두 단계로 이루어집니다.

    • 1단계 — 히프 만들기: 정렬할 데이터를 모두 히프에 넣습니다
    • 2단계 — 하나씩 꺼내기: 히프에서 최솟값(또는 최댓값)을 반복해서 꺼내 순서대로 나열합니다

    시간복잡도는 O(n log n)으로, 퀵 정렬이나 병합 정렬과 같은 등급입니다.

    ✅ 예시로 확인

    [38, 21, 45, 10, 7]을 히프 정렬로 오름차순 정렬해 봅시다.

    1단계: 최소 히프에 모두 삽입
  → 히프 내부 상태: 7이 루트(꼭대기)에 위치

2단계: 하나씩 꺼내기
  꺼낸 순서: 7 → 10 → 21 → 38 → 45

결과: [7, 10, 21, 38, 45] ✅ 정렬 완료!
    graph TD subgraph "1단계: 최소 히프 구성" A["7"] --> B["10"] A --> C["45"] B --> D["38"] B --> E["21"] end
    graph LR H["최소 히프"] -->|"꺼내기 1"| R1["7"] R1 -->|"꺼내기 2"| R2["10"] R2 -->|"꺼내기 3"| R3["21"] R3 -->|"꺼내기 4"| R4["38"] R4 -->|"꺼내기 5"| R5["45"]

    개념 2: 파이썬 heapq로 히프 정렬 구현하기¶

    파이썬에는 히프를 다루는 heapq 모듈이 내장되어 있습니다. 9차시에서 배운 것을 기억하시나요? 이것을 활용하면 히프 정렬을 단 4줄로 구현할 수 있습니다.

    import heapq

def heap_sort(data):
    heap = []
    for item in data:
        heapq.heappush(heap, item)   # 1단계: 히프에 넣기

    result = []
    while heap:
        result.append(heapq.heappop(heap))  # 2단계: 꺼내기

    return result

    💡 알아보기: heapq.heappush()는 값을 넣으면서 히프 구조를 자동 유지하고, heapq.heappop()은 가장 작은 값을 꺼내면서 히프를 재정비합니다. 각 연산이 O(log n)이고, n개를 반복하므로 전체 O(n log n)입니다.

    사실 heapq에는 이 과정을 한 번에 해주는 함수도 있습니다.

    import heapq

data = [38, 21, 45, 10, 7]
sorted_data = heapq.nsmallest(len(data), data)
print(sorted_data)  # [7, 10, 21, 38, 45]

    개념 3: 해시 — 키를 주소로 변환하여 바로 찾기¶

    🎪 비유로 시작

    학교 사물함을 생각해 보세요.

    • 학생 이름: "김민수"
    • 사물함 번호: 23번

    "김민수"라는 이름을 듣는 순간, 23번 사물함으로 바로 갑니다. 1번부터 100번까지 하나하나 열어보지 않죠! 이때 "이름 → 사물함 번호"로 변환하는 규칙이 바로 해시 함수입니다.

    📖 정확한 정의

    • 해시 함수(Hash Function): 데이터(키)를 받아 고정된 크기의 숫자(해시값)로 변환하는 함수
    • 해시 테이블(Hash Table): 해시값을 인덱스(주소)로 사용하는 배열. 데이터를 저장하고 찾는 자료구조
    • 해시값(Hash Value): 해시 함수가 계산해낸 결과 숫자
    graph LR K1["키: '김민수'"] --> HF["해시 함수"] HF --> HV["해시값: 23"] HV --> T["해시 테이블의 23번 칸"]

    ✅ 예시로 확인 — 간단한 해시 함수 만들어 보기

    가장 단순한 해시 함수: 나머지 연산

    def simple_hash(key, table_size):
    """키를 테이블 크기로 나눈 나머지를 해시값으로 사용"""
    if isinstance(key, str):
        # 문자열이면 각 글자의 유니코드 합을 사용
        key = sum(ord(c) for c in key)
    return key % table_size

    table_size = 10

print(simple_hash("cat", 10))   # (99+97+116) % 10 = 312 % 10 = 2
print(simple_hash("dog", 10))   # (100+111+103) % 10 = 314 % 10 = 4
print(simple_hash("ant", 10))   # (97+110+116) % 10 = 323 % 10 = 3

    "cat"은 2번 칸, "dog"은 4번 칸, "ant"는 3번 칸에 저장됩니다. 찾을 때도 같은 해시 함수를 쓰면 바로 해당 칸으로 갈 수 있습니다!

    🤔 생각해보기: 만약 두 개의 다른 키가 같은 해시값을 갖게 되면 어떻게 될까요? 이것을 충돌(Collision)이라고 합니다. 이 문제를 해결하는 방법은 여러 가지가 있지만, 가장 직관적인 것은 같은 칸에 리스트로 여러 개를 연결하는 체이닝(Chaining) 방식입니다.

    개념 4: 파이썬 딕셔너리 = 해시 테이블¶

    사실 여러분은 이미 해시 테이블을 매일 사용하고 있었습니다! 바로 파이썬의 딕셔너리(dict)입니다.

    # 딕셔너리 = 내부적으로 해시 테이블!
phonebook = {
    "김민수": "010-1234-5678",
    "이영희": "010-8765-4321",
    "박철수": "010-1111-2222"
}

# 이름으로 바로 찾기 → O(1)!
print(phonebook["김민수"])  # 010-1234-5678

    리스트에서 찾기 vs 딕셔너리에서 찾기

    graph TD subgraph "리스트: 순차 탐색 O(n)" L1["0번: 확인❌"] --> L2["1번: 확인❌"] L2 --> L3["2번: 확인❌"] L3 --> L4["3번: 찾았다!✅"] end subgraph "딕셔너리: 해시 탐색 O(1)" K["'김민수'"] --> HF2["해시 함수"] HF2 --> D["바로 도착!✅"] end

    💡 알아보기: 딕셔너리의 검색, 삽입, 삭제는 평균 O(1)입니다. 데이터가 100만 개든 1억 개든, 한 번의 해시 계산으로 바로 찾아갑니다. 이것이 해시 테이블의 위력입니다!

    파이썬 내장 hash() 함수 확인하기

    # 파이썬이 내부적으로 사용하는 해시 함수
print(hash("cat"))      # 실행할 때마다 다를 수 있음
print(hash("dog"))      
print(hash(42))         # 정수의 해시값
print(hash((1, 2, 3)))  # 튜플의 해시값

    ⚠️ 리스트(list)는 변경 가능(mutable)하므로 해시값을 가질 수 없습니다. 그래서 딕셔너리의 키로 리스트를 사용할 수 없는 것입니다!

    🔨 따라하기¶

    Step 1: 히프 정렬 직접 구현하고 과정 관찰하기¶

    import heapq

def heap_sort_verbose(data):
    """히프 정렬 과정을 시각적으로 보여주는 함수"""
    print(f"원본 데이터: {data}")
    print(f"\n{'='*40}")
    print("1단계: 히프에 삽입")
    print(f"{'='*40}")

    heap = []
    for item in data:
        heapq.heappush(heap, item)
        print(f"  {item} 삽입 → 히프 상태: {heap}")

    print(f"\n{'='*40}")
    print("2단계: 히프에서 꺼내기")
    print(f"{'='*40}")

    result = []
    step = 1
    while heap:
        value = heapq.heappop(heap)
        result.append(value)
        print(f"  꺼내기 {step}: {value} → 결과: {result}")
        step += 1

    print(f"\n정렬 완료: {result}")
    return result

# 실행해 보세요!
heap_sort_verbose([38, 21, 45, 10, 7])

    Step 3: 간단한 해시 테이블 직접 만들기¶

    class SimpleHashTable:
    """이해를 위한 간단한 해시 테이블 구현"""

    def __init__(self, size=10):
        self.size = size
        self.table = [[] for _ in range(size)]  # 체이닝 방식

    def _hash(self, key):
        """해시 함수: 키를 인덱스로 변환"""
        if isinstance(key, str):
            return sum(ord(c) for c in key) % self.size
        return key % self.size

    def put(self, key, value):
        """데이터 저장"""
        index = self._hash(key)
        # 이미 같은 키가 있으면 값 업데이트
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value)
                return
        self.table[index].append((key, value))
        print(f"  '{key}' → 해시값 {index}번 칸에 저장")

    def get(self, key):
        """데이터 검색"""
        index = self._hash(key)
        for k, v in self.table[index]:
            if k == key:
                return v
        return None

    def show(self):
        """테이블 내부 상태 출력"""
        print("\n해시 테이블 내부:")
        for i, bucket in enumerate(self.table):
            if bucket:
                print(f"  [{i}번 칸] → {bucket}")

    Step 4: 해시 테이블 사용해 보기¶

    ht = SimpleHashTable(size=10)

print("데이터 저장:")
ht.put("cat", "고양이")
ht.put("dog", "강아지")
ht.put("ant", "개미")
ht.put("bee", "벌")

ht.show()

print(f"\n'cat' 검색 → {ht.get('cat')}")
print(f"'dog' 검색 → {ht.get('dog')}")

    Step 6: 정렬·탐색 알고리즘 종합 비교¶

    import heapq, time, random

def measure_sort_time(sort_func, data):
    """정렬 함수의 실행 시간 측정"""
    test_data = data.copy()
    start = time.time()
    sort_func(test_data)
    return time.time() - start

def heap_sort(data):
    heap = []
    for item in data:
        heapq.heappush(heap, item)
    return [heapq.heappop(heap) for _ in range(len(heap))]

def selection_sort(data):
    arr = data.copy()
    for i in range(len(arr)):
        min_idx = i
        for j in range(i+1, len(arr)):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

# 5000개 데이터로 비교
data = random.sample(range(50000), 5000)

t1 = measure_sort_time(selection_sort, data)
t2 = measure_sort_time(heap_sort, data)
t3 = measure_sort_time(sorted, data)  # 파이썬 내장 (팀소트)

print(f"선택 정렬  O(n²)    : {t1:.4f}초")
print(f"히프 정렬  O(n log n): {t2:.4f}초")
print(f"내장 정렬  O(n log n): {t3:.4f}초")

# 내림차순 히프 정렬 (부호를 뒤집는 트릭)
def heap_sort_desc(data):
    """내림차순 히프 정렬"""
    heap = []
    for item in data:
        heapq.heappush(heap, -item)  # 부호 반전하여 삽입
    return [-heapq.heappop(heap) for _ in range(len(heap))]

print(f"내림차순: {heap_sort_desc(original)}")

# ============================================
# 2. 간단한 해시 테이블
# ============================================
class SimpleHashTable:
    def __init__(self, size=10):
        self.size = size
        self.table = [[] for _ in range(size)]

    def _hash(self, key):
        if isinstance(key, str):
            return sum(ord(c) for c in key) % self.size
        return key % self.size

    def put(self, key, value):
        index = self._hash(key)
        for i, (k, v) in enumerate(self.table[index]):
            if k == key:
                self.table[index][i] = (key, value)
                return
        self.table[index].append((key, value))

    def get(self, key):
        index = self._hash(key)
        for k, v in self.table[index]:
            if k == key:
                return v
        return None

# 테스트

ht.put("banana", 2000)
ht.put("cherry", 5000)

    실수 3: 해시 테이블의 O(1)이 "항상" 보장된다고 생각하는 것

    O(1)은 평균적인 시간복잡도입니다. 모든 키가 같은 해시값을 가지는 최악의 경우, O(n)까지 느려질 수 있습니다. 하지만 좋은 해시 함수를 사용하면 이런 일은 극히 드뭅니다. 파이썬의 내장 해시 함수는 충분히 잘 설계되어 있으므로 실전에서는 O(1)로 간주해도 됩니다.
