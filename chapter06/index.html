    Chapter 06. 트리의 개념 - 가계도로 이해하는 계층 구조¶

    Part 2 | [1권] 비선형 자료구조 - 트리와 히프

    🎯 이 장에서 배우는 것¶

    • 트리의 기본 용어(루트, 노드, 간선, 높이, 깊이, 리프 등)를 정확히 설명할 수 있다
    • 이진 트리의 정의와 종류(완전 이진 트리, 포화 이진 트리, 편향 이진 트리)를 구분할 수 있다
    • 딕셔너리와 리스트를 활용하여 트리 구조를 파이썬으로 표현할 수 있다
    • 주어진 계층 구조(가계도, 조직도)를 코드로 변환할 수 있다

    💡 왜 이걸 배우나요?¶

    지금까지 우리는 배열, 연결 리스트, 스택, 큐 같은 자료구조를 배웠습니다. 이것들의 공통점은 뭘까요? 바로 데이터가 한 줄로 나열된다는 것입니다. 이런 구조를 선형 자료구조라고 합니다.

    하지만 세상의 모든 데이터가 한 줄로 늘어서 있지는 않습니다.

    • 🏠 가계도: 할아버지 아래 아버지와 삼촌, 그 아래 나와 사촌들
    • 🏢 회사 조직도: 사장님 아래 부장님들, 그 아래 과장님들
    • 📁 컴퓨터 폴더 구조: C드라이브 안에 문서 폴더, 그 안에 과제 폴더…

    이 구조들은 모두 위에서 아래로 가지를 치며 뻗어나가는 형태입니다. 마치 나무를 뒤집어 놓은 것 같죠? 이것이 바로 트리(Tree) 입니다.

    트리는 검색, 정렬, 파일 시스템, 데이터베이스 등 컴퓨터 과학의 핵심 곳곳에서 사용됩니다. 이 장에서 트리의 기초를 탄탄히 다져봅시다!

    📚 핵심 개념¶

    개념 1: 트리란 무엇인가? 🌳¶

    비유로 시작해볼까요?

    여러분의 가계도를 떠올려보세요. 맨 위에 할아버지·할머니가 계시고, 그 아래에 부모님 세대, 또 그 아래에 여러분 세대가 있습니다. 한 사람(부모)에게서 여러 사람(자녀)이 뻗어나가는 구조입니다.

    정확한 정의

    트리(Tree) 는 노드(Node) 들이 간선(Edge) 으로 연결된 계층적 자료구조입니다. 사이클(순환)이 없고, 하나의 루트 노드에서 시작하여 아래로 가지를 치며 뻗어나갑니다.

    graph TD A["할아버지 👴<br/>(루트 노드)"] A --> B["아버지 👨"] A --> C["삼촌 👨"] B --> D["나 🧑"] B --> E["여동생 👧"] C --> F["사촌 형 🧑"]

    💡 알아보기: 왜 이름이 '트리(나무)'일까요? 구조를 뒤집어 보면 뿌리(루트)에서 줄기를 거쳐 잎으로 뻗어나가는 나무와 닮았기 때문입니다. 다만 컴퓨터 과학에서는 뿌리가 위에, 잎이 아래에 있는 뒤집힌 나무를 그립니다.

    개념 2: 트리의 핵심 용어 📖¶

    트리를 이야기하려면 공통 언어가 필요합니다. 아래 트리를 보면서 용어를 하나씩 익혀봅시다.

    graph TD A["A<br/>루트 노드"] A --> B["B"] A --> C["C"] B --> D["D"] B --> E["E"] C --> F["F"] E --> G["G"] E --> H["H"]

    🔑 핵심 용어 정리

    • 노드(Node): 트리를 구성하는 기본 단위. 위 그림에서 A, B, C, D, E, F, G, H 모두 노드입니다
    • 간선(Edge): 노드와 노드를 연결하는 선. A→B, A→C, B→D 등이 간선입니다
    • 루트(Root): 트리의 최상단 노드. 부모가 없는 유일한 노드. 위 그림에서 A
    • 부모(Parent): 어떤 노드의 바로 윗 노드. B의 부모는 A, G의 부모는 E
    • 자식(Children): 어떤 노드의 바로 아랫 노드. A의 자식은 B와 C, E의 자식은 G와 H
    • 형제(Sibling): 같은 부모를 가진 노드들. B와 C는 형제, G와 H는 형제
    • 리프(Leaf): 자식이 없는 노드(말단 노드). D, F, G, H가 리프 노드
    • 서브 트리(Subtree): 어떤 노드를 루트로 하는 부분 트리. B를 루트로 한 서브트리는 B-D-E-G-H
    • 차수(Degree): 어떤 노드의 자식 수. A의 차수는 2, E의 차수는 2, D의 차수는 0

    깊이와 높이 — 가장 헷갈리는 용어!

    • 깊이(Depth): 루트에서 해당 노드까지의 간선 수. 루트(A)의 깊이 = 0, B의 깊이 = 1, G의 깊이 = 3
    • 높이(Height): 해당 노드에서 가장 먼 리프까지의 간선 수. G의 높이 = 0, E의 높이 = 1, 트리의 높이 = 루트의 높이 = 3
    • 레벨(Level): 깊이와 같은 의미로 사용 (교재에 따라 레벨 0 또는 레벨 1부터 시작)

    🤔 생각해보기: 위 트리에서 노드 F의 깊이와 높이는 각각 얼마일까요? → 깊이 = 2 (A→C→F, 간선 2개), 높이 = 0 (리프 노드이므로)

    개념 3: 이진 트리의 종류 🌲🌲¶

    비유로 시작해볼까요?

    만약 "각 부모는 최대 2명의 자녀만 가질 수 있다"는 규칙이 있는 특별한 가계도가 있다면? 이것이 바로 이진 트리입니다.

    정확한 정의

    이진 트리(Binary Tree) 는 모든 노드의 자식이 최대 2개인 트리입니다. 자식을 왼쪽 자식과 오른쪽 자식으로 구분합니다.

    이진 트리는 가장 많이 사용되는 트리 형태입니다. 이진 트리에도 여러 종류가 있습니다.

    ① 포화 이진 트리 (Full/Perfect Binary Tree)

    모든 레벨이 노드로 꽉 차 있는 트리입니다. 빈 자리가 하나도 없습니다.

    graph TD A["1"] --> B["2"] A --> C["3"] B --> D["4"] B --> E["5"] C --> F["6"] C --> G["7"]
    • 높이가 h이면 노드 수 = 2^(h+1) − 1
    • 위 예시: 높이 2, 노드 수 = 2³ − 1 = 7개

    ② 완전 이진 트리 (Complete Binary Tree)

    마지막 레벨을 제외하고 모두 채워져 있으며, 마지막 레벨은 왼쪽부터 차례로 채워진 트리입니다.

    graph TD A["1"] --> B["2"] A --> C["3"] B --> D["4"] B --> E["5"] C --> F["6"]
    • 노드 6이 왼쪽부터 채워져 있으므로 ✅ 완전 이진 트리
    • 만약 노드 6 없이 노드 7만 있다면? ❌ 완전 이진 트리가 아닙니다

    💡 알아보기: 완전 이진 트리는 다음 장에서 배울 히프(Heap) 의 기반이 됩니다. 매우 중요한 개념이니 꼭 기억하세요!

    ③ 편향 이진 트리 (Skewed Binary Tree)

    모든 노드가 한쪽 방향으로만 자식을 가지는 트리입니다. 사실상 연결 리스트와 같은 형태가 됩니다.

    graph TD A["1"] --> B["2"] B --> C["3"] C --> D["4"]
    • 트리의 장점(빠른 탐색)을 살리지 못하는 최악의 경우입니다

    세 가지 이진 트리 비교

    graph LR subgraph 편향["편향 이진 트리"] direction TB P1["1"] --> P2["2"] P2 --> P3["3"] end subgraph 완전["완전 이진 트리"] direction TB C1["1"] --> C2["2"] C1 --> C3["3"] C2 --> C4["4"] C2 --> C5["5"] end subgraph 포화["포화 이진 트리"] direction TB F1["1"] --> F2["2"] F1 --> F3["3"] F2 --> F4["4"] F2 --> F5["5"] F3 --> F6["6"] F3 --> F7["7"] end

    개념 4: 파이썬으로 트리 표현하기 🐍¶

    트리를 코드로 표현하는 방법은 여러 가지입니다. 여기서는 가장 직관적인 두 가지 방법을 배웁니다.

    방법 1: 딕셔너리로 표현 (부모 → 자식 리스트)

    각 노드를 키(key)로, 그 자식들을 값(value) 리스트로 저장합니다.

    # 부모: [자식들] 형태
tree = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': ['G', 'H'],
    'F': [],
    'G': [],
    'H': []
}

    이 방법은 어떤 노드의 자식을 찾기 쉽다는 장점이 있습니다.

    방법 2: 클래스로 노드 표현 (이진 트리 전용)

    이진 트리는 자식이 최대 2개이므로 left와 right로 명확하게 표현할 수 있습니다.

    class Node:
    def __init__(self, data):
        self.data = data      # 노드가 저장하는 값
        self.left = None      # 왼쪽 자식
        self.right = None     # 오른쪽 자식

    🤔 생각해보기: 방법 1은 자식이 몇 개든 상관없지만, 방법 2는 이진 트리에만 적합합니다. 상황에 맞게 선택하면 됩니다!

    🔨 따라하기: 가계도를 코드로 만들기¶

    아래 가계도를 파이썬 코드로 구현해봅시다.

    graph TD 할아버지["할아버지 👴"] --> 아버지["아버지 👨"] 할아버지 --> 삼촌["삼촌 👨"] 아버지 --> 나["나 🧑"] 아버지 --> 여동생["여동생 👧"] 삼촌 --> 사촌["사촌 🧑"]

    Step 1: 딕셔너리로 트리 구조 만들기¶

    # 가계도를 딕셔너리로 표현
family_tree = {
    '할아버지': ['아버지', '삼촌'],
    '아버지': ['나', '여동생'],
    '삼촌': ['사촌'],
    '나': [],
    '여동생': [],
    '사촌': []
}

print("가계도:", family_tree)

    실행 결과 

    가계도: {'할아버지': ['아버지', '삼촌'], '아버지': ['나', '여동생'], '삼촌': ['사촌'], '나': [], '여동생': [], '사촌': []}

    Step 2: 트리 정보 조회 함수 만들기¶

    def get_children(tree, node):
    """자식 노드 목록 반환"""
    return tree.get(node, [])

def get_parent(tree, child):
    """부모 노드 찾기"""
    for parent, children in tree.items():
        if child in children:
            return parent
    return None  # 루트 노드는 부모가 없음

def is_leaf(tree, node):
    """리프 노드인지 확인"""
    return len(tree.get(node, [])) == 0

    # 테스트
print("아버지의 자식:", get_children(family_tree, '아버지'))
print("나의 부모:", get_parent(family_tree, '나'))
print("여동생은 리프?", is_leaf(family_tree, '여동생'))
print("아버지는 리프?", is_leaf(family_tree, '아버지'))

    실행 결과 

    아버지의 자식: ['나', '여동생']
나의 부모: 아버지
여동생은 리프? True
아버지는 리프? False

    Step 3: 루트 찾기와 깊이 계산¶

    def find_root(tree):
    """루트 노드 찾기: 어떤 노드의 자식에도 나타나지 않는 노드"""
    all_children = set()
    for children in tree.values():
        all_children.update(children)

    for node in tree.keys():
        if node not in all_children:
            return node
    return None

def get_depth(tree, target):
    """루트에서 target까지의 깊이 계산"""
    depth = 0
    current = target
    while True:
        parent = get_parent(tree, current)
        if parent is None:  # 루트에 도달
            break
        depth += 1
        current = parent
    return depth

    # 테스트
root = find_root(family_tree)
print(f"루트 노드: {root}")
print(f"'나'의 깊이: {get_depth(family_tree, '나')}")
print(f"'사촌'의 깊이: {get_depth(family_tree, '사촌')}")
print(f"'할아버지'의 깊이: {get_depth(family_tree, '할아버지')}")

    실행 결과 

    루트 노드: 할아버지
'나'의 깊이: 2
'사촌'의 깊이: 2
'할아버지'의 깊이: 0

    Step 5: 트리의 모든 노드 출력하기 (트리 순회 맛보기)¶

    트리의 모든 노드를 방문하는 것을 순회(Traversal) 라고 합니다. 여기서는 간단히 맛만 봅시다.

    def print_tree(node, level=0):
    """트리를 들여쓰기로 시각화"""
    if node is not None:
        print("  " * level + f"├─ {node.data}")
        print_tree(node.left, level + 1)
        print_tree(node.right, level + 1)

    📝 전체 코드¶

    아래 코드를 복사하여 실행하면 이 장에서 배운 내용을 한 번에 확인할 수 있습니다.

    # ============================================
# Chapter 06: 트리의 개념
# ============================================

# --- 1. 딕셔너리로 트리 표현 ---
family_tree = {
    '할아버지': ['아버지', '삼촌'],
    '아버지': ['나', '여동생'],
    '삼촌': ['사촌'],
    '나': [],
    '여동생': [],
    '사촌': []
}

def get_children(tree, node):
    return tree.get(node, [])

def get_parent(tree, child):
    for parent, children in tree.items():
        if child in children:
            return parent
    return None

def is_leaf(tree, node):
    return len(tree.get(node, [])) == 0

def find_root(tree):
    all_children = set()
    for children in tree.values():
        all_children.update(children)
    for node in tree.keys():
        if node not in all_children:
            return node
    return None

def get_depth(tree, target):
    depth = 0
    current = target
    while True:
        parent = get_parent(tree, current)
        if parent is None:
            break
        depth += 1
        current = parent
    return depth

print("=== 딕셔너리 트리 ===")
print(f"루트: {find_root(family_tree)}")
print(f"아버지의 자식: {get_children(family_tree, '아버지')}")
print(f"나의 부모: {get_parent(family_tree, '나')}")
print(f"여동생은 리프? {is_leaf(family_tree, '여동생')}")
print(f"'사촌'의 깊이: {get_depth(family_tree, '사촌')}")
print()

# --- 2. 클래스로 이진 트리 표현 ---
class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None

root = Node('할아버지')
root.left = Node('아버지')
root.right = Node('삼촌')
root.left.left = Node('나')
root.left.right = Node('여동생')
root.right.left = Node('사촌')

def print_tree(node, level=0):
    if node is not None:
        print("  " * level + f"├─ {node.data}")
        print_tree(node.left, level + 1)
        print_tree(node.right, level + 1)

def count_nodes(node):
    if node is None:
        return 0
    return 1 + count_nodes(node.left) + count_nodes(node.right)

def tree_height(node):
    if node is None:
        return -1
    return 1 + max(tree_height(node.left), tree_height(node.right))

print("=== 클래스 기반 이진 트리 ===")
print_tree(root)
print(f"\n총 노드 수: {count_nodes(root)}")
print(f"트리 높이: {tree_height(root)}")

    ⚠️ 자주 하는 실수¶

    실수 1: 깊이(Depth)와 높이(Height)를 혼동한다 😵

    • 깊이는 위에서 아래로 센다 → 루트에서 해당 노드까지
    • 높이는 아래에서 위로 센다 → 해당 노드에서 가장 먼 리프까지
    • 루트의 깊이 = 0, 리프의 높이 = 0으로 기억하세요!

    실수 2: 완전 이진 트리에서 "왼쪽부터"를 잊는다 😰

    graph TD subgraph 완전이진트리아님["❌ 완전 이진 트리 아님"] direction TB X1["1"] --> X2["2"] X1 --> X3["3"] X3 --> X6[" "] X3 --> X7["7"] end subgraph 완전이진트리["✅ 완전 이진 트리"] direction TB O1["1"] --> O2["2"] O1 --> O3["3"] O2 --> O4["4"] O2 --> O5[" "] end style X6 fill:transparent,stroke:transparent style O5 fill:transparent,stroke:transparent

    마지막 레벨은 반드시 왼쪽에서 오른쪽 순서로 채워져야 합니다. 중간에 빈 자리가 있으면 완전 이진 트리가 아닙니다.

    실수 3: 딕셔너리에서 리프 노드를 빼먹는다 🔑

    'A': ['B', 'C'],
    'B': ['D']

    'A': ['B', 'C'],
    'B': ['D'],

}
