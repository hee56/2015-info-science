    Chapter 12. 자료구조 종합 정리 — 중간 점검과 실전 연습¶

    Part 3 | [1권] 그래프와 자료구조 종합

    🎯 이 장에서 배우는 것¶

    • 리스트·스택·큐·트리·히프·그래프의 특성을 한눈에 비교할 수 있다
    • 문제 상황을 읽고 적절한 자료구조를 선택하여 근거를 설명할 수 있다
    • 실생활 시나리오를 코드로 구현하며 자료구조를 종합 활용할 수 있다
    • 최종 프로젝트에 활용할 자료구조를 미리 구상하고 기초 설계를 시작할 수 있다

    💡 왜 이걸 배우나요?¶

    지금까지 우리는 리스트, 스택, 큐, 트리, 히프, 그래프라는 여섯 가지 자료구조를 하나씩 배워왔습니다. 각각의 개념은 이해했지만, 실제 문제 앞에서 "어떤 자료구조를 써야 하지?"라는 질문에 답하기는 쉽지 않습니다.

    이것은 마치 공구 상자 🧰와 같습니다. 망치, 드라이버, 펜치, 톱을 각각 사용할 줄 알아도, 실제 가구를 조립할 때는 어느 순간에 어떤 공구를 꺼내야 하는지를 판단하는 능력이 필요합니다.

    이번 장은 그 판단력을 기르는 시간입니다. 지금까지의 지식을 정리하고, 실전 시나리오에 적용해 보겠습니다.

    📚 핵심 개념¶

    개념 1: 자료구조 특성 비교 — 한눈에 보는 큰 그림 🗺️¶

    비유로 시작

    여섯 가지 자료구조를 교통수단에 비유해 봅시다. - 리스트 → 자가용 (자유롭게 어디든, 하지만 정체 가능) - 스택 → 엘리베이터 (마지막에 탄 사람이 먼저 내림) - 큐 → 버스 정류장 줄 (먼저 온 사람이 먼저 탑승) - 트리 → 지하철 노선도 (계층적 분기) - 히프 → 응급실 (가장 급한 환자가 먼저) - 그래프 → 도시 전체 도로망 (모든 것이 연결 가능)

    정확한 비교

    graph LR subgraph 선형 구조 A[리스트<br/>순서대로 저장<br/>삽입·삭제 유연] B[스택<br/>LIFO<br/>후입선출] C[큐<br/>FIFO<br/>선입선출] end subgraph 비선형 구조 D[트리<br/>계층 관계<br/>부모-자식] E[히프<br/>최대·최소 즉시<br/>우선순위] F[그래프<br/>다대다 관계<br/>네트워크] end A --> B B --> C D --> E E --> F

    핵심 특성 정리

    • 리스트(List): 데이터를 순서대로 저장. 인덱스로 접근 O(1), 중간 삽입·삭제 O(n)
    • 스택(Stack): 후입선출(LIFO). push/pop 모두 O(1). 되돌리기, 괄호 검사에 활용
    • 큐(Queue): 선입선출(FIFO). enqueue/dequeue 모두 O(1). 대기열, BFS에 활용
    • 트리(Tree): 계층 구조. 이진탐색트리 탐색 평균 O(log n). 폴더 구조, 의사결정에 활용
    • 히프(Heap): 완전이진트리 기반. 최댓값/최솟값 꺼내기 O(log n). 우선순위 큐의 핵심
    • 그래프(Graph): 정점과 간선의 자유로운 연결. 네트워크, 경로 탐색에 활용

    📌 알아보기: 시간 복잡도에서 O(1)은 "데이터가 아무리 많아도 한 번에 처리", O(log n)은 "반씩 줄여가며 처리", O(n)은 "하나씩 다 확인"이라는 뜻입니다.

    개념 2: 자료구조 선택 기준 — 어떤 상황에 무엇을? 🤔¶

    비유로 시작

    음식점에서 주문 방식을 생각해 봅시다. - 뷔페(리스트) → 아무 음식이나 자유롭게 접근 - 접시 쌓기(스택) → 맨 위 접시만 사용 - 줄 서기(큐) → 순서대로 처리 - 메뉴 카테고리(트리) → 한식 > 국물 > 된장찌개처럼 분류 - VIP 우선 입장(히프) → 등급이 높은 손님 먼저 - SNS 추천(그래프) → 친구의 친구를 연결

    선택 기준 플로우차트

    flowchart TD Q1{"데이터 간의<br/>관계가 있나요?"} Q1 -- "없음 (단순 목록)" --> Q2{"순서가<br/>중요한가요?"} Q1 -- "있음" --> Q3{"관계가<br/>계층적인가요?"} Q2 -- "자유 접근" --> R1["✅ 리스트"] Q2 -- "마지막 것만 필요" --> R2["✅ 스택"] Q2 -- "먼저 온 것부터" --> R3["✅ 큐"] Q3 -- "예 (부모-자식)" --> Q4{"최대/최소가<br/>핵심인가요?"} Q3 -- "아니오 (다대다)" --> R6["✅ 그래프"] Q4 -- "예" --> R5["✅ 히프"] Q4 -- "아니오" --> R4["✅ 트리"]

    💡 생각해보기: 카카오톡 채팅방의 메시지 목록은 어떤 자료구조에 가까울까요? 새 메시지가 아래에 추가되고, 오래된 메시지부터 보여주니까 큐의 성격이 강합니다!

    개념 3: 실생활 시나리오 분석법 📋¶

    문제를 보고 자료구조를 선택하는 3단계 분석법을 익혀봅시다.

    1단계 — 데이터 파악: "무엇을 저장하는가?" 2단계 — 연산 파악: "주로 어떤 작업을 하는가?" (삽입? 삭제? 탐색? 정렬?) 3단계 — 관계 파악: "데이터 사이에 어떤 관계가 있는가?" (순서? 계층? 네트워크?)

    예시: 택배 분류 시스템 - 1단계: 택배 상자(이름, 주소, 무게)를 저장 - 2단계: 들어온 순서대로 처리, 급한 택배 우선 처리도 필요 - 3단계: 순서 관계 + 우선순위 - 결론: 기본은 큐, 급한 건 히프(우선순위 큐) 활용

    개념 4: NetworkX로 미리 보는 그래프 시각화 🌐¶

    최종 프로젝트에서 활용할 수 있는 NetworkX 라이브러리를 간단히 소개합니다. NetworkX는 파이썬에서 그래프를 만들고 시각화하는 도구입니다.

    # NetworkX 맛보기 (설치: pip install networkx matplotlib)
import networkx as nx
import matplotlib.pyplot as plt

G = nx.Graph()
G.add_edges_from([("서울", "대전"), ("대전", "대구"), 
                  ("대구", "부산"), ("서울", "원주"),
                  ("원주", "강릉")])

nx.draw(G, with_labels=True, node_color="skyblue", 
        node_size=2000, font_size=14, font_family="Malgun Gothic")
plt.title("도시 연결 그래프")
plt.show()

    📌 알아보기: font_family를 설정해야 한글이 깨지지 않습니다. Mac에서는 "AppleGothic", Windows에서는 "Malgun Gothic"을 사용하세요.

    🔨 따라하기 — 실전 시나리오 코딩¶

    Step 1: 시나리오 읽고 자료구조 선택하기¶

    다음 시나리오를 읽고, 어떤 자료구조를 쓸지 먼저 생각해 보세요.

    시나리오: 게임 랭킹 시스템 🎮

    온라인 게임에서 플레이어의 점수를 관리합니다. - 새로운 플레이어가 점수를 등록합니다 - 항상 최고 점수 플레이어를 빠르게 확인해야 합니다 - 상위 3명을 출력해야 합니다

    분석: - 1단계(데이터): 플레이어 이름과 점수 - 2단계(연산): 삽입 + 최댓값 추출 - 3단계(관계): 우선순위 관계 - 선택: 최대 히프(Max Heap) ✅

    Step 2: 게임 랭킹 시스템 구현하기¶

    import heapq

class GameRanking:
    def __init__(self):
        self.heap = []  # 최대 히프를 위해 음수로 저장

    def add_player(self, name, score):
        # heapq는 최소 히프이므로 -score로 저장하면 최대 히프 효과
        heapq.heappush(self.heap, (-score, name))
        print(f"  등록: {name} ({score}점)")

    def get_top(self, n=3):
        # 원본을 유지하면서 상위 n명 추출
        temp = self.heap[:]
        result = []
        for _ in range(min(n, len(temp))):
            score, name = heapq.heappop(temp)
            result.append((name, -score))
        return result

# 실행
ranking = GameRanking()
print("🎮 플레이어 등록:")
ranking.add_player("Alice", 1500)
ranking.add_player("Bob", 2300)
ranking.add_player("Charlie", 1800)
ranking.add_player("Diana", 2700)
ranking.add_player("Eve", 2100)

print("\n🏆 상위 3명:")
for i, (name, score) in enumerate(ranking.get_top(3), 1):
    print(f"  {i}위: {name} - {score}점")

    Step 3: 택배 분류 시스템 구현하기¶

    시나리오: 택배 분류 센터 📦

    • 일반 택배는 도착 순서대로 처리합니다
    • "급송" 택배는 일반보다 항상 먼저 처리합니다

    분석: 일반은 큐, 급송은 우선순위가 필요 → 우선순위 큐(히프)

    import heapq

class DeliveryCenter:
    def __init__(self):
        self.queue = []
        self.order = 0  # 도착 순서 기록

    def receive(self, package_name, is_express=False):
        priority = 0 if is_express else 1  # 급송=0(높음), 일반=1(낮음)
        self.order += 1
        heapq.heappush(self.queue, (priority, self.order, package_name))
        tag = "🔴 급송" if is_express else "⚪ 일반"
        print(f"  접수: [{tag}] {package_name}")

    def process_next(self):
        if self.queue:
            priority, order, name = heapq.heappop(self.queue)
            tag = "급송" if priority == 0 else "일반"
            print(f"  처리: [{tag}] {name}")
            return name
        print("  처리할 택배가 없습니다.")
        return None

# 실행
center = DeliveryCenter()
print("📦 택배 접수:")
center.receive("서울→부산 의류")
center.receive("대전→광주 전자제품", is_express=True)
center.receive("인천→제주 식품")
center.receive("수원→대구 의약품", is_express=True)

print("\n🚚 처리 순서:")
for _ in range(4):
    center.process_next()

  접수: [⚪ 일반] 서울→부산 의류
  접수: [🔴 급송] 대전→광주 전자제품
  접수: [⚪ 일반] 인천→제주 식품
  접수: [🔴 급송] 수원→대구 의약품

🚚 처리 순서:

    Step 4: 웹 브라우저 뒤로 가기 구현 (스택 활용)¶

    class Browser:
    def __init__(self):
        self.back_stack = []
        self.current = "홈페이지"

    def visit(self, url):
        self.back_stack.append(self.current)
        self.current = url
        print(f"  방문: {url}")

    def go_back(self):
        if self.back_stack:
            prev = self.back_stack.pop()
            print(f"  뒤로 가기 → {prev}")
            self.current = prev
        else:
            print("  더 이상 뒤로 갈 수 없습니다!")

    def show_current(self):
        print(f"  현재 페이지: {self.current}")

# 실행
browser = Browser()
print("🌐 웹 브라우저 시뮬레이션:")
browser.visit("google.com")
browser.visit("youtube.com")
browser.visit("github.com")
browser.show_current()

print("\n⬅️ 뒤로 가기:")
browser.go_back()
browser.show_current()
browser.go_back()
browser.show_current()

    Step 5: 파일 탐색기 구현 (트리 활용)¶

    class Folder:
    def __init__(self, name):
        self.name = name
        self.children = []

    def add(self, child):
        self.children.append(child)
        return child

    def show(self, level=0):
        indent = "  " * level
        icon = "📁" if self.children else "📄"
        print(f"{indent}{icon} {self.name}")
        for child in self.children:
            child.show(level + 1)

# 파일 구조 만들기
root = Folder("내 컴퓨터")

        "answer": "리스트",
        "reason": "순서 있는 목록을 자유롭게 수정하므로 리스트가 적합합니다."

def run_quiz():
    print("=" * 50)
    print("🧠 자료구조 선택 퀴즈!")
    print("  보기: 리스트, 스택, 큐, 트리, 히프, 그래프")
    print("=" * 50)

    random.shuffle(scenarios)
    score = 0
    total = min(4, len(scenarios))  # 4문제 출제

    for i, s in enumerate(scenarios[:total], 1):
        print(f"\n📋 문제 {i}: {s['question']}")
        user = input("  👉 적절한 자료구조는? ").strip()

        if user == s["answer"]:
            print(f"  ✅ 정답! {s['reason']}")
            score += 1
        else:
            print(f"  ❌ 오답. 정답은 '{s['answer']}'입니다.")
            print(f"     💡 {s['reason']}")

    print(f"\n{'=' * 50}")
    print(f"🏆 결과: {total}문제 중 {score}문제 정답!")

    if score == total:
        print("  🎉 완벽합니다! 자료구조 마스터!")
    elif score >= total // 2:
        print("  👍 잘하고 있어요! 틀린 부분만 복습하세요.")
    else:
        print("  📖 각 자료구조의 특성을 다시 정리해 봅시다.")

# 실행
run_quiz()

    ⚠️ 자주 하는 실수¶

    실수 1: "배열이면 다 리스트" 사고방식 🚫

    파이썬의 리스트(list)로 스택, 큐, 히프를 모두 구현할 수 있지만, "파이썬 리스트를 쓴다 = 리스트 자료구조"가 아닙니다. list를 append/pop으로만 쓰면 스택이고, collections.deque를 쓰면 큐입니다. 자료구조는 "어떤 규칙으로 쓰느냐"가 핵심입니다.

    실수 2: 큐가 필요한데 스택을 선택 🔄

    "순서대로 처리"라는 말이 나오면 반사적으로 확인하세요. - 먼저 들어온 것부터 처리 → 큐(FIFO) - 나중에 들어온 것부터 처리 → 스택(LIFO)

    이 둘을 헷갈리면 전혀 다른 결과가 나옵니다!

    실수 3: 트리와 그래프를 구분하지 못함 🌳↔️🌐

    • 트리: 부모→자식 방향의 계층 관계, 순환(사이클)이 없음
    • 그래프: 아무 노드끼리나 연결 가능, 순환 가능

    조직도, 폴더 구조 → 트리 / 도로망, SNS 관계 → 그래프
