    Chapter 19: networkX로 그래프 시각화 - 프로젝트 도구 익히기¶

    Part 5 | [2권] 그래프 알고리즘과 프로젝트

    🎯 이 장에서 배우는 것¶

    • networkX 라이브러리를 설치하고 그래프를 생성(Graph, DiGraph)할 수 있다
    • 노드·간선을 추가하고, 가중치 등 속성을 부여할 수 있다
    • matplotlib과 연동하여 그래프를 시각적으로 표현할 수 있다
    • networkX 내장 함수로 DFS, BFS, 다익스트라를 실행하고 직접 구현한 결과와 비교할 수 있다

    💡 왜 이걸 배우나요?¶

    지금까지 우리는 그래프를 인접 리스트나 딕셔너리로 직접 만들고, DFS·BFS·다익스트라도 한 줄 한 줄 코딩했습니다. 이 과정은 원리를 이해하는 데 꼭 필요했습니다.

    하지만 실전 프로젝트에서는 어떨까요? 🤔

    🏗️ 비유: 목수가 되려면 망치질부터 배워야 합니다. 하지만 실제 건물을 지을 때는 전동 드릴을 씁니다. networkX는 그래프 알고리즘의 전동 드릴입니다.

    networkX를 사용하면 복잡한 그래프를 몇 줄로 생성하고, 알고리즘을 한 줄로 실행하며, 결과를 그림으로 즉시 확인할 수 있습니다. 다음 챕터(Chapter 20)의 최종 프로젝트에서 이 도구를 적극 활용하게 되므로, 지금 확실히 익혀둡시다!

    📚 핵심 개념¶

    개념 1: networkX란?¶

    비유부터 📦

    레고 블록 세트를 생각해보세요. 블록(노드)을 꺼내고, 연결 막대(간선)로 이어 붙이고, 색을 칠하고(속성 부여), 완성품을 사진 찍는(시각화) 것까지 — 이 모든 게 한 상자에 들어 있습니다. networkX가 바로 그 상자입니다.

    정확한 정의

    networkX는 파이썬에서 그래프(네트워크)를 생성·조작·분석하기 위한 오픈소스 라이브러리입니다. 수학적 그래프 이론의 거의 모든 기능을 내장하고 있습니다.

    설치 방법

    pip install networkx matplotlib

    📌 알아보기: matplotlib은 그래프를 "그림으로 그릴 때" 필요합니다. networkX 자체는 데이터 구조와 알고리즘만 담당하고, 시각화는 matplotlib에 맡깁니다.

    개념 2: 그래프 생성과 노드·간선 추가¶

    비유부터 🗺️

    지도를 그린다고 상상하세요. 먼저 빈 종이(그래프 객체)를 꺼내고, 도시를 점으로 찍고(노드 추가), 도시 사이에 도로를 긋습니다(간선 추가).

    networkX의 두 가지 그래프 타입

    • nx.Graph() — 무방향 그래프: 간선에 방향이 없음 (친구 관계처럼 쌍방향)
    • nx.DiGraph() — 방향 그래프(Directed Graph): 간선에 화살표가 있음 (팔로우 관계처럼 일방향 가능)
    graph LR subgraph "무방향 Graph" A --- B B --- C A --- C end subgraph "방향 DiGraph" D --> E E --> F F --> D end

    예시 코드

    import networkx as nx

# 무방향 그래프 생성
G = nx.Graph()

# 노드 추가 (하나씩)
G.add_node("서울")
G.add_node("부산")

# 노드 여러 개를 한 번에
G.add_nodes_from(["대전", "대구", "광주"])

# 간선 추가 (두 노드를 연결)
G.add_edge("서울", "대전")
G.add_edge("대전", "대구")

# 간선 여러 개를 한 번에
G.add_edges_from([("대구", "부산"), ("서울", "광주"), ("광주", "대전")])

# 확인
print("노드:", list(G.nodes()))
print("간선:", list(G.edges()))
print("노드 수:", G.number_of_nodes())
print("간선 수:", G.number_of_edges())

    출력 결과 

    노드: ['서울', '부산', '대전', '대구', '광주']
간선: [('서울', '대전'), ('서울', '광주'), ('부산', '대구'), ('대전', '대구'), ('대전', '광주')]
노드 수: 5
간선 수: 5

    개념 3: 속성(가중치) 부여¶

    비유부터 🏷️

    도시 사이의 도로를 그렸다면, 이제 각 도로 위에 거리(km)를 적어야 내비게이션이 작동하겠죠? 이것이 간선 속성(가중치)입니다. 노드에도 인구 같은 속성을 붙일 수 있습니다.

    # 가중치가 있는 간선 추가
G_weighted = nx.Graph()
G_weighted.add_edge("서울", "대전", weight=140)
G_weighted.add_edge("대전", "대구", weight=120)
G_weighted.add_edge("대구", "부산", weight=80)
G_weighted.add_edge("서울", "부산", weight=325)

# 노드에 속성 부여
G_weighted.nodes["서울"]["population"] = 970
G_weighted.nodes["부산"]["population"] = 340

# 속성 확인
print(G_weighted["서울"]["대전"]["weight"])  # 140
print(G_weighted.nodes["서울"])  # {'population': 970}

    💡 생각해보기: weight라는 이름은 networkX에서 특별합니다. 최단 경로 알고리즘이 기본적으로 weight 속성을 비용으로 사용합니다.

    개념 4: matplotlib 연동 시각화¶

    비유부터 🎨

    데이터만으로는 그래프의 전체 구조를 파악하기 어렵습니다. 시각화는 그래프의 X-ray 사진과 같습니다. 한눈에 구조가 보입니다.

    networkX는 nx.draw() 함수로 matplotlib을 활용해 그래프를 그립니다.

    import networkx as nx
import matplotlib.pyplot as plt

G = nx.Graph()
G.add_edges_from([
    ("Alice", "Bob"), ("Alice", "Carol"),
    ("Bob", "David"), ("Carol", "David"),
    ("David", "Eve")
])

# 기본 시각화
nx.draw(G, with_labels=True, node_color="skyblue",
        node_size=700, font_size=12, font_weight="bold")
plt.title("친구 관계 그래프")
plt.show()

    주요 옵션 정리

    • with_labels=True — 노드 이름 표시
    • node_color — 노드 색상 (문자열 또는 리스트)
    • node_size — 노드 크기 (기본값 300)
    • edge_color — 간선 색상
    • font_size — 라벨 글자 크기
    • pos — 노드 위치를 직접 지정하는 딕셔너리

    레이아웃 알고리즘

    노드를 어디에 배치할지 결정하는 것이 레이아웃입니다.

    # 다양한 레이아웃 시도
pos_spring = nx.spring_layout(G)       # 스프링 모델 (기본)
pos_circular = nx.circular_layout(G)   # 원형 배치
pos_shell = nx.shell_layout(G)         # 동심원 배치

# 원형 레이아웃으로 그리기
nx.draw(G, pos=pos_circular, with_labels=True,
        node_color="lightgreen", node_size=800)
plt.title("원형 레이아웃")
plt.show()
    graph TD A["spring_layout"] --> D["노드가 서로 밀고 당기며 자연스럽게 배치"] B["circular_layout"] --> E["모든 노드가 원 위에 균등 배치"] C["shell_layout"] --> F["동심원 형태로 계층 배치"]

    🔨 따라하기: 소셜 네트워크 만들고 분석하기¶

    Step 1: 그래프 생성과 데이터 입력¶

    학교 동아리 친구 관계를 그래프로 만들어봅시다.

    import networkx as nx
import matplotlib.pyplot as plt

# 방향 없는 친구 관계 그래프
friend = nx.Graph()

# 친구 관계 데이터
friendships = [
    ("민수", "지영"), ("민수", "현우"), ("민수", "서연"),
    ("지영", "현우"), ("지영", "하늘"),
    ("현우", "서연"), ("현우", "준호"),
    ("서연", "하늘"),
    ("준호", "태희"), ("준호", "하늘"),
    ("태희", "하늘")
]

friend.add_edges_from(friendships)
print(f"동아리 인원: {friend.number_of_nodes()}명")
print(f"친구 관계: {friend.number_of_edges()}개")

    동아리 인원: 6명
친구 관계: 10개

    Step 2: 시각화하기¶

    # 보기 좋은 레이아웃 생성
pos = nx.spring_layout(friend, seed=42)  # seed로 배치 고정

# 각 노드의 친구 수에 비례하는 크기 설정
node_sizes = [friend.degree(n) * 300 for n in friend.nodes()]

nx.draw(friend, pos=pos,
        with_labels=True,
        node_color="salmon",
        node_size=node_sizes,
        font_size=11,
        font_family="sans-serif",
        edge_color="gray",
        width=2)

plt.title("동아리 친구 관계", fontsize=14)
plt.show()

    📌 알아보기: friend.degree(n)은 노드 n에 연결된 간선의 수, 즉 친구 수를 반환합니다. 친구가 많을수록 노드가 크게 그려집니다!

    Step 3: 기본 정보 분석¶

    # 각 사람의 친구 수 (차수, degree)
print("=== 친구 수 ===")
for person in friend.nodes():
    print(f"  {person}: {friend.degree(person)}명")

# 가장 친구가 많은 사람
max_person = max(friend.nodes(), key=lambda n: friend.degree(n))
print(f"\n가장 인기 많은 사람: {max_person} ({friend.degree(max_person)}명)")

    === 친구 수 ===
  민수: 3명
  지영: 3명
  현우: 4명
  서연: 3명
  하늘: 3명
  준호: 3명
  태희: 2명

가장 인기 많은 사람: 현우 (4명)

    Step 4: networkX 내장 알고리즘 — DFS, BFS¶

    이전 챕터에서 직접 구현했던 DFS, BFS를 networkX로 실행해봅시다.

    # DFS (깊이 우선 탐색)
dfs_result = list(nx.dfs_edges(friend, source="민수"))
print("DFS 탐색 순서 (간선):")
for edge in dfs_result:
    print(f"  {edge[0]} → {edge[1]}")

print()

# BFS (너비 우선 탐색)
bfs_tree = nx.bfs_tree(friend, source="민수")
print("BFS 탐색 트리의 간선:")
for edge in bfs_tree.edges():
    print(f"  {edge[0]} → {edge[1]}")

    💡 생각해보기: nx.dfs_edges()는 DFS로 방문하는 간선 순서를 반환하고, nx.bfs_tree()는 BFS 탐색 결과를 트리(그래프 객체)로 반환합니다. 우리가 수십 줄 작성했던 코드가 단 한 줄입니다!

    Step 5: networkX 내장 알고리즘 — 최단 경로¶

    가중치 그래프에서 다익스트라를 실행해봅시다.

    # 가중치 그래프 생성 (도시 간 거리)
city = nx.Graph()
city.add_edge("서울", "대전", weight=140)
city.add_edge("대전", "대구", weight=120)
city.add_edge("대구", "부산", weight=80)
city.add_edge("서울", "부산", weight=325)
city.add_edge("서울", "광주", weight=270)
city.add_edge("광주", "부산", weight=200)

# 최단 경로 (다익스트라)
path = nx.shortest_path(city, source="서울", target="부산", weight="weight")
length = nx.shortest_path_length(city, source="서울", target="부산", weight="weight")

print(f"서울 → 부산 최단 경로: {' → '.join(path)}")
print(f"최단 거리: {length}km")

    서울 → 부산 최단 경로: 서울 → 대전 → 대구 → 부산
최단 거리: 340km

    Step 6: 직접 구현 vs 라이브러리 비교¶

    # 직접 구현한 다익스트라 (이전 챕터 복습)
import heapq

def dijkstra_manual(graph_dict, start, end):
    dist = {node: float('inf') for node in graph_dict}
    dist[start] = 0
    prev = {node: None for node in graph_dict}
    pq = [(0, start)]

    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph_dict[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                prev[v] = u
                heapq.heappush(pq, (dist[v], v))

    # 경로 복원
    path = []
    node = end
    while node:
        path.append(node)
        node = prev[node]
    return path[::-1], dist[end]

# 같은 그래프를 딕셔너리로 표현
graph_dict = {
    "서울": [("대전", 140), ("부산", 325), ("광주", 270)],
    "대전": [("서울", 140), ("대구", 120)],
    "대구": [("대전", 120), ("부산", 80)],
    "부산": [("대구", 80), ("서울", 325), ("광주", 200)],
    "광주": [("서울", 270), ("부산", 200)]
}

path_m, length_m = dijkstra_manual(graph_dict, "서울", "부산")

# networkX 결과
path_nx = nx.shortest_path(city, "서울", "부산", weight="weight")
length_nx = nx.shortest_path_length(city, "서울", "부산", weight="weight")

print("=== 결과 비교 ===")
print(f"직접 구현: {' → '.join(path_m)}, 거리={length_m}")
print(f"networkX:  {' → '.join(path_nx)}, 거리={length_nx}")
print(f"결과 일치: {path_m == path_nx and length_m == length_nx}")

    • 진우 → 수빈, 진우 → 유나
    • 수빈 → 유나, 수빈 → 도현
    • 유나 → 도현
    • 도현 → 진우

    import networkx as nx

G = nx.DiGraph()

    ("진우", "수빈"), ("진우", "유나"),

    ("유나", "도현"),

bfs = nx.bfs_tree(G, source="진우")
