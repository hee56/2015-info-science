    Chapter 08. 이진 탐색 트리 — 정렬된 데이터의 빠른 검색¶

    Part 2 | [1권] 비선형 자료구조 — 트리와 히프 ⏱️ 예상 소요 시간: 2시간

    🎯 이 장에서 배우는 것¶

    • 이진 탐색 트리(BST)의 정의와 왼쪽 < 부모 < 오른쪽 속성을 설명할 수 있다
    • 데이터를 하나씩 삽입하며 BST가 만들어지는 과정을 손으로 추적할 수 있다
    • 파이썬으로 BST의 삽입·탐색 함수를 구현하고 실행할 수 있다
    • 중위 순회로 정렬된 결과를 얻는 원리를 이해할 수 있다
    • BST의 효율성과 한계(편향 트리)를 파악하고, 리스트 탐색과 비교할 수 있다

    💡 왜 이걸 배우나요?¶

    1,000페이지짜리 영어 사전에서 "python"이라는 단어를 찾는다고 상상해 보세요. 첫 페이지부터 한 장씩 넘기는 사람은 없죠? 대부분 중간쯤을 펼친 뒤, 찾는 단어가 앞쪽에 있으면 왼쪽 절반을, 뒤쪽에 있으면 오른쪽 절반을 다시 펼칩니다.

    이 "반씩 줄여 가며 찾기" 전략을 트리 구조로 구현한 것이 바로 이진 탐색 트리(Binary Search Tree, BST) 입니다.

    🔑 핵심 한 줄 — BST를 쓰면 데이터가 아무리 많아도 한 단계 내려갈 때마다 탐색 범위가 절반으로 줄어듭니다.

    📚 핵심 개념¶

    개념 1: 이진 탐색 트리의 정의¶

    ① 비유로 시작

    도서관 책꽂이를 생각해 보세요. 가운데 칸에 기준 책(예: "ㅁ"으로 시작)을 놓고, 그보다 앞 글자인 책은 왼쪽 칸, 뒷 글자인 책은 오른쪽 칸에 꽂습니다. 왼쪽·오른쪽 칸 안에서도 같은 규칙을 반복하면, 어떤 책이든 빠르게 찾을 수 있습니다.

    ② 정확한 정의

    이진 탐색 트리(BST)는 다음 세 가지 규칙을 모든 노드에서 만족하는 이진 트리입니다.

    • 왼쪽 서브트리의 모든 값 < 부모 노드 값
    • 오른쪽 서브트리의 모든 값 > 부모 노드 값
    • 왼쪽·오른쪽 서브트리도 각각 BST이다 (재귀적 정의)

    ③ 예시로 확인

    숫자 [8, 3, 10, 1, 6, 14]를 순서대로 삽입하면 아래 트리가 만들어집니다.

    graph TB A((8)) --> B((3)) A --> C((10)) B --> D((1)) B --> E((6)) C --> F((" ")) C --> G((14)) style F fill:none,stroke:none

    확인! 어떤 노드를 골라도 "왼쪽 < 부모 < 오른쪽" 규칙이 성립합니다. 노드 3을 보면 왼쪽 1 < 3, 오른쪽 6 > 3 ✔️

    개념 2: 삽입 — 자리를 찾아 내려가기¶

    새 값을 넣을 때는 루트부터 시작해서 비교 → 이동을 반복합니다.

    📖 알아보기: 삽입 알고리즘

    1. 루트와 비교한다.
    2. 새 값이 작으면 왼쪽, 크면 오른쪽으로 이동한다.
    3. 이동할 자리가 비어 있으면 그곳에 새 노드를 만든다.
    4. 비어 있지 않으면 1~3을 반복한다.

    예시: 위 트리에 4를 삽입하는 과정

    • 4 < 8 → 왼쪽(3)으로
    • 4 > 3 → 오른쪽(6)으로
    • 4 < 6 → 왼쪽 — 비어 있다! → 여기에 삽입 ✅
    graph TB A((8)) --> B((3)) A --> C((10)) B --> D((1)) B --> E((6)) E --> H((4)) E --> I((" ")) C --> F((" ")) C --> G((14)) style F fill:none,stroke:none style I fill:none,stroke:none style H fill:#FFDAB9,stroke:#E67E22,stroke-width:2px

    개념 3: 탐색 — 반씩 버리기¶

    탐색도 삽입과 같은 경로를 따라갑니다. 한 단계 내려갈 때마다 나머지 절반을 통째로 무시할 수 있으므로 매우 빠릅니다.

    📖 알아보기: 탐색 알고리즘

    1. 현재 노드의 값과 찾는 값을 비교한다.
    2. 같으면 → 탐색 성공 🎉
    3. 찾는 값이 작으면 → 왼쪽 자식으로 이동
    4. 찾는 값이 크면 → 오른쪽 자식으로 이동
    5. 자식이 없으면 → 탐색 실패 ❌

    예시: 6을 찾는 과정

    • 6 < 8 → 왼쪽(3)
    • 6 > 3 → 오른쪽(6)
    • 6 == 6 → 찾았다! (비교 3번)

    만약 리스트 [8, 3, 10, 1, 6, 14]에서 순차 탐색했다면 최대 6번 비교해야 합니다.

    개념 4: 효율성과 한계 — 편향 트리¶

    균형 잡힌 BST에서 높이는 약 log₂n입니다. 데이터가 1,000개라도 약 10번의 비교로 원하는 값을 찾을 수 있죠.

    그런데 [1, 2, 3, 4, 5]처럼 이미 정렬된 순서로 삽입하면 어떻게 될까요?

    graph TB A((1)) --> X1((" ")) A --> B((2)) B --> X2((" ")) B --> C((3)) C --> X3((" ")) C --> D((4)) D --> X4((" ")) D --> E((5)) style X1 fill:none,stroke:none style X2 fill:none,stroke:none style X3 fill:none,stroke:none style X4 fill:none,stroke:none

    오른쪽으로만 길게 늘어진 편향 트리(Skewed Tree) 가 됩니다. 사실상 연결 리스트와 같아서 탐색에 O(n) 이 걸립니다.

    💬 생각해보기: 편향 트리 문제를 어떻게 해결할 수 있을까요? → 이후 장에서 배울 AVL 트리, 히프 등이 바로 이 문제의 해결책입니다.

    BST 성능 비교

    • 균형 BST — 탐색 O(log n), 삽입 O(log n)
    • 편향 BST — 탐색 O(n), 삽입 O(n)
    • 리스트 순차 탐색 — 탐색 O(n)

    🔨 따라하기¶

    파이썬 딕셔너리를 이용해 BST를 구현합니다. 각 노드는 {'value': 값, 'left': None, 'right': None} 형태입니다.

    Step 1: 노드 만들기¶

    def make_node(value):
    """하나의 BST 노드를 딕셔너리로 생성"""
    return {'value': value, 'left': None, 'right': None}

    Step 2: 삽입 함수 구현¶

    def insert(node, value):
    """BST에 새 값을 삽입 (재귀)"""
    if node is None:
        return make_node(value)

    if value < node['value']:
        node['left'] = insert(node['left'], value)
    elif value > node['value']:
        node['right'] = insert(node['right'], value)
    # 같은 값은 무시 (중복 허용하지 않음)

    return node

    Step 3: 탐색 함수 구현¶

    def search(node, value):
    """BST에서 값을 탐색, 찾으면 True / 없으면 False"""
    if node is None:
        return False

    if value == node['value']:
        return True
    elif value < node['value']:
        return search(node['left'], value)
    else:
        return search(node['right'], value)

    Step 4: 중위 순회 — 정렬 결과 확인¶

    중위 순회(In-order)는 왼쪽 → 부모 → 오른쪽 순서로 방문합니다. BST에서 중위 순회를 하면 오름차순 정렬된 결과를 얻습니다.

    def inorder(node, result=None):
    """중위 순회로 정렬된 리스트 반환"""
    if result is None:
        result = []
    if node is not None:
        inorder(node['left'], result)
        result.append(node['value'])
        inorder(node['right'], result)
    return result

    Step 5: 전체 동작 테스트¶

    # 트리 생성 및 데이터 삽입
root = None
data = [8, 3, 10, 1, 6, 14, 4]

for value in data:
    root = insert(root, value)

# 탐색 테스트
print("6 탐색:", search(root, 6))   # True
print("7 탐색:", search(root, 7))   # False

# 중위 순회 → 정렬된 결과
print("중위 순회:", inorder(root))   # [1, 3, 4, 6, 8, 10, 14]

    Step 6: 실행 결과 확인¶

    6 탐색: True
7 탐색: False
중위 순회: [1, 3, 4, 6, 8, 10, 14]

    🎉 삽입 순서는 [8, 3, 10, 1, 6, 14, 4]였지만, 중위 순회 결과는 자동으로 정렬되어 나옵니다!

    📝 전체 코드¶

    # ===== 이진 탐색 트리 (BST) - 딕셔너리 기반 구현 =====

def make_node(value):
    """BST 노드 생성"""
    return {'value': value, 'left': None, 'right': None}


def insert(node, value):
    """BST 삽입 (재귀)"""
    if node is None:
        return make_node(value)
    if value < node['value']:
        node['left'] = insert(node['left'], value)
    elif value > node['value']:
        node['right'] = insert(node['right'], value)
    return node


def search(node, value):
    """BST 탐색 — 찾으면 True, 없으면 False"""
    if node is None:
        return False
    if value == node['value']:
        return True
    elif value < node['value']:
        return search(node['left'], value)
    else:
        return search(node['right'], value)


def inorder(node, result=None):
    """중위 순회 — 정렬된 리스트 반환"""
    if result is None:
        result = []
    if node is not None:
        inorder(node['left'], result)
        result.append(node['value'])
        inorder(node['right'], result)
    return result


# ===== 실행 =====
if __name__ == "__main__":
    root = None
    data = [8, 3, 10, 1, 6, 14, 4]

    for v in data:
        root = insert(root, v)
        print(f"{v} 삽입 후 중위 순회: {inorder(root)}")

    print()
    print("6 탐색:", search(root, 6))
    print("7 탐색:", search(root, 7))
    print("최종 중위 순회:", inorder(root))

    실행 결과:

    8 삽입 후 중위 순회: [8]
3 삽입 후 중위 순회: [3, 8]
10 삽입 후 중위 순회: [3, 8, 10]
1 삽입 후 중위 순회: [1, 3, 8, 10]
6 삽입 후 중위 순회: [1, 3, 6, 8, 10]
14 삽입 후 중위 순회: [1, 3, 6, 8, 10, 14]
4 삽입 후 중위 순회: [1, 3, 4, 6, 8, 10, 14]

6 탐색: True
7 탐색: False
최종 중위 순회: [1, 3, 4, 6, 8, 10, 14]

    ⚠️ 자주 하는 실수¶

    실수 1: insert의 반환값을 무시하기 😵

    # ❌ 잘못된 사용
insert(root, 5)  # root가 None일 때 트리가 만들어지지 않음

# ✅ 올바른 사용
root = insert(root, 5)  # 반환값을 반드시 받아야 함

    root가 None인 상태에서 반환값을 받지 않으면 새 노드가 연결되지 않습니다.

    실수 2: 같은 값 처리를 빼먹기 🔄

    BST는 보통 중복 값을 허용하지 않습니다. insert 함수에서 value == node['value']인 경우를 처리하지 않으면 무한 재귀에 빠지거나 중복 노드가 생길 수 있습니다. 우리 코드에서는 같은 값이 들어오면 아무것도 하지 않고 넘어갑니다(elif로 처리).

    실수 3: 편향 트리를 간과하기 📉

    [1, 2, 3, 4, 5]처럼 정렬된 데이터를 넣으면 사실상 연결 리스트가 됩니다. BST라고 해서 항상 O(log n)이 보장되는 것이 아닙니다. 입력 순서가 성능을 좌우한다는 점을 꼭 기억하세요.

    ✅ 스스로 점검하기¶

    기본 문제¶

    문제 1. 다음 숫자를 순서대로 빈 BST에 삽입했을 때의 트리 모양을 그려 보세요.

    [5, 2, 8, 1, 3, 7, 9]

    문제 2. 위에서 만든 트리에서 7을 탐색할 때, 어떤 노드를 순서대로 방문하나요?

    💡 정답 보기 **문제 1 답:**
    graph TB A((5)) --> B((2)) A --> C((8)) B --> D((1)) B --> E((3)) C --> F((7)) C --> G((9))
    **문제 2 답:** `5` → `8` → `7` (3번 비교) - `7 > 5` → 오른쪽(8) - `7 < 8` → 왼쪽(7) - `7 == 7` → 찾았다!

    응용 문제¶

    문제 3. [1, 2, 3, 4, 5]를 순서대로 삽입하면 어떤 모양의 트리가 되나요? 이 트리에서 5를 찾으려면 몇 번 비교해야 하나요?

    💡 정답 보기 오른쪽으로만 이어지는 편향 트리가 됩니다. `5`를 찾으려면 `1→2→3→4→5` 총 **5번** 비교해야 합니다. 리스트 순차 탐색과 동일한 성능입니다.

    심화 문제¶

    문제 4. 같은 데이터 {1, 2, 3, 4, 5}를 가지고도 높이가 최소인 BST를 만들 수 있습니다. 어떤 순서로 삽입하면 될까요? 직접 삽입 순서를 정하고 트리를 그려 보세요.

    💡 힌트 정렬된 배열의 **가운데 값**을 먼저 넣으면 균형 잡힌 트리가 만들어집니다. 삽입 순서: `3, 1(또는 2), 4(또는 5), 2, 5` — 가운데를 루트로 삼고, 왼쪽·오른쪽 절반의 가운데를 다시 넣는 방식입니다.

    🚀 더 해보기¶

    💬 도전 토론: 편향 트리 해결하기

    [1, 2, 3, ..., 100]을 순서대로 BST에 넣으면 높이가 100인 편향 트리가 됩니다. 이 문제를 해결하려면 어떤 방법이 있을까요? 아래 아이디어를 참고해서 친구와 토론해 보세요.

    • 아이디어 A: 삽입 전에 데이터를 무작위로 섞는다
    • 아이디어 B: 삽입할 때마다 트리가 기울어지면 자동으로 회전시킨다 (→ AVL 트리의 원리!)
    • 아이디어 C: 처음부터 정렬된 배열의 가운데부터 넣는다

    🛠️ 코딩 도전: search 함수를 재귀 없이 반복문(while)으로 바꿔 보세요. 아래 뼈대를 완성해 보세요.

    def search_iterative(node, value):
    current = node
    while current is not None:
        if value == current['value']:
            return True
        elif value < current['value']:
            current = current['left']
        else:
            current = current['right']
    return False

    🔗 다음 장으로¶

    📖 정리하기

    이번 장에서 우리는 이진 탐색 트리(BST) 의 핵심을 배웠습니다.

    • "왼쪽 < 부모 < 오른쪽" 이라는 단순한 규칙 하나로 빠른 탐색이 가능하다
    • 삽입·탐색 모두 루트에서 아래로 내려가며 비교하는 같은 패턴이다
    • 중위 순회를 하면 정렬된 결과가 자동으로 나온다
    • 삽입 순서에 따라 편향 트리가 될 수 있고, 이때 성능이 O(n)으로 떨어진다

    다음 장에서는 BST의 편향 문제를 근본적으로 해결하고, 항상 빠른 삽입·삭제를 보장하는 히프(Heap) 자료구조를 배웁니다. "가장 큰 값" 또는 "가장 작은 값"을 순식간에 꺼내야 할 때, 히프가 어떻게 활약하는지 함께 알아보겠습니다! 🌳➡️🏔️
