    Chapter 10. 그래프의 개념 - 관계를 연결하는 자료구조¶

    Part 3 | [1권] 그래프와 자료구조 종합

    🎯 이 장에서 배우는 것¶

    • 그래프의 기본 용어(정점, 간선, 인접, 차수, 경로)를 정확히 설명할 수 있다
    • 방향 그래프, 무방향 그래프, 가중치 그래프를 구분하고 실생활 예시를 들 수 있다
    • 인접 행렬(2차원 리스트)로 그래프를 파이썬에서 표현할 수 있다
    • 인접 리스트(딕셔너리)로 그래프를 파이썬에서 표현할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분의 SNS 친구 목록을 떠올려 보세요. "나 → 민수 → 지영 → 수현"처럼 친구의 친구를 따라가다 보면, 의외의 사람과 연결되어 있다는 걸 발견할 때가 있죠?

    이런 "연결 관계" 는 세상 곳곳에 숨어 있습니다.

    • 🚇 지하철 노선도: 역(점)과 역 사이를 잇는 노선(선)
    • 🌐 인터넷: 컴퓨터(점)와 컴퓨터를 잇는 네트워크 케이블(선)
    • 🗺️ 네비게이션: 교차로(점)와 도로(선), 그리고 거리(숫자)

    이 모든 것을 하나의 자료구조로 표현할 수 있는 것이 바로 그래프(Graph) 입니다. 그래프를 이해하면 "최단 경로 찾기", "추천 시스템", "소셜 네트워크 분석" 같은 문제를 체계적으로 풀 수 있게 됩니다.

    📌 알아보기: 지금까지 배운 트리(Tree)도 사실 그래프의 한 종류입니다! 트리는 "순환이 없고, 하나의 루트를 가진 연결 그래프"라는 특수한 조건을 만족하는 그래프예요.

    📚 핵심 개념¶

    개념 1: 그래프란 무엇인가?¶

    🎭 비유로 시작

    학교 운동장에 학생 5명이 서 있다고 상상해 보세요. 서로 아는 사이인 학생들끼리 실로 연결한다면, 실과 학생들이 만들어내는 모양 — 그것이 바로 그래프입니다.

    📖 정확한 정의

    그래프(Graph)는 정점(Vertex) 의 집합과 간선(Edge) 의 집합으로 이루어진 자료구조입니다.

    • 정점(Vertex, 또는 Node): 그래프의 "점". 데이터를 담는 단위입니다.
    • 간선(Edge): 그래프의 "선". 두 정점 사이의 관계를 나타냅니다.

    수학적으로는 G = (V, E)로 표기합니다. V는 정점들의 집합, E는 간선들의 집합입니다.

    ✅ 예시로 확인

    친구 관계를 그래프로 표현해 봅시다.

    graph LR A["민수"] --- B["지영"] A --- C["수현"] B --- D["태호"] C --- D D --- E["하나"]
    • 정점(V): {민수, 지영, 수현, 태호, 하나} → 총 5개
    • 간선(E): {민수-지영, 민수-수현, 지영-태호, 수현-태호, 태호-하나} → 총 5개

    개념 2: 꼭 알아야 할 그래프 용어¶

    🎭 비유로 시작

    지하철 노선도를 보면서 용어를 하나씩 짚어 봅시다. 역이 "정점", 역과 역을 잇는 구간이 "간선"이라면, 나머지 용어도 자연스럽게 이해할 수 있습니다.

    📖 정확한 정의

    • 인접(Adjacent): 두 정점이 간선으로 직접 연결된 상태. "민수와 지영은 인접하다"
    • 차수(Degree): 한 정점에 연결된 간선의 수. 친구가 3명이면 차수는 3
    • 경로(Path): 한 정점에서 다른 정점까지 간선을 따라 이동하는 순서. "민수 → 지영 → 태호"
    • 경로의 길이: 경로에 포함된 간선의 수. 위 경로의 길이는 2
    • 사이클(Cycle): 시작 정점으로 다시 돌아오는 경로. "민수 → 수현 → 태호 → 지영 → 민수"

    ✅ 예시로 확인

    위의 친구 관계 그래프에서 확인해 봅시다.

    • 태호의 차수: 지영, 수현, 하나와 연결 → 차수 = 3
    • 민수의 차수: 지영, 수현과 연결 → 차수 = 2
    • 민수에서 하나까지의 경로: 민수 → 지영 → 태호 → 하나 (길이 3) 또는 민수 → 수현 → 태호 → 하나 (길이 3)

    💡 생각해보기: 모든 정점의 차수를 더하면 어떤 값이 될까요? 간선 하나는 양쪽 정점의 차수를 각각 1씩 올리므로, 차수의 합 = 간선 수 × 2 가 됩니다. 위 예시에서 확인해 보세요! (2+1+2+3+1 = 9? 아닙니다. 직접 세어 보면 2+1+2+3+1 = 9가 아니라 5×2 = 10이어야 합니다. 하나의 차수를 다시 확인해 보세요!)

    개념 3: 그래프의 종류¶

    🎭 비유로 시작

    도로에도 종류가 있죠? 양방향 도로, 일방통행, 그리고 고속도로처럼 통행료가 붙는 도로. 그래프도 마찬가지입니다.

    📖 정확한 정의와 구분

    ① 무방향 그래프 (Undirected Graph)

    간선에 방향이 없습니다. A와 B가 연결되면 A→B, B→A 모두 이동 가능합니다.

    graph LR A["서울"] --- B["대전"] B --- C["부산"] A --- C
    • 실생활 예시: SNS 친구 관계(서로 친구), 양방향 도로

    ② 방향 그래프 (Directed Graph, Digraph)

    간선에 방향이 있습니다. A→B가 있다고 B→A가 있는 건 아닙니다.

    graph LR A["나"] -->|"팔로우"| B["연예인"] C["나"] -->|"팔로우"| D["뉴스채널"] B -->|"팔로우"| D
    • 실생활 예시: 인스타그램 팔로우(일방적), 일방통행 도로, 수강 선수과목

    ③ 가중치 그래프 (Weighted Graph)

    간선에 숫자(가중치)가 붙어 있습니다. 거리, 비용, 시간 등을 나타냅니다.

    graph LR A["서울"] ---|"140km"| B["대전"] B ---|"200km"| C["부산"] A ---|"325km"| C
    • 실생활 예시: 네비게이션(거리), 항공권(가격), 네트워크(전송 속도)

    📌 정리하기: 방향 유무와 가중치 유무는 독립적입니다. 따라서 "방향 + 가중치 그래프"도 가능합니다! 예를 들어, 서울→부산 고속버스 요금과 부산→서울 고속버스 요금이 다를 수 있죠.

    개념 4: 그래프를 코드로 표현하는 두 가지 방법¶

    그래프를 컴퓨터에서 다루려면 코드로 저장해야 합니다. 대표적인 두 가지 방법을 배워봅시다.

    방법 ① 인접 행렬 (Adjacency Matrix)

    정점이 N개일 때, N×N 크기의 2차원 리스트를 만들어서 연결 여부를 0과 1로 표시합니다.

    graph LR V0["0"] --- V1["1"] V0 --- V2["2"] V1 --- V2 V2 --- V3["3"]

    위 그래프의 인접 행렬은 다음과 같습니다.

    • 0행: [0, 1, 1, 0] → 정점 0은 1, 2와 연결
    • 1행: [1, 0, 1, 0] → 정점 1은 0, 2와 연결
    • 2행: [1, 1, 0, 1] → 정점 2는 0, 1, 3과 연결
    • 3행: [0, 0, 1, 0] → 정점 3은 2와 연결

    방법 ② 인접 리스트 (Adjacency List)

    각 정점에 대해 연결된 정점들의 목록을 저장합니다. 파이썬에서는 딕셔너리와 리스트를 활용합니다.

    • 정점 0의 이웃: [1, 2]
    • 정점 1의 이웃: [0, 2]
    • 정점 2의 이웃: [0, 1, 3]
    • 정점 3의 이웃: [2]

    두 방법의 비교

    graph TD subgraph 인접행렬["인접 행렬"] M1["✅ 두 정점 연결 확인: 빠름 O(1)"] M2["❌ 메모리: 정점² 만큼 필요"] M3["👍 간선이 많을 때 유리"] end subgraph 인접리스트["인접 리스트"] L1["❌ 두 정점 연결 확인: 느림 O(차수)"] L2["✅ 메모리: 간선 수만큼만 필요"] L3["👍 간선이 적을 때 유리"] end

    💡 생각해보기: 정점이 1,000개인데 간선이 10개뿐인 그래프라면, 인접 행렬은 1,000×1,000 = 1,000,000칸을 만들어야 합니다. 인접 리스트는 10개의 연결 정보만 저장하면 되죠. 어떤 방법이 효율적일까요?

    🔨 따라하기¶

    다음 친구 관계를 그래프로 표현해 봅시다.

    친구 관계:
- 0번(민수) ↔ 1번(지영)
- 0번(민수) ↔ 2번(수현)
- 1번(지영) ↔ 2번(수현)
- 2번(수현) ↔ 3번(태호)

    Step 1: 인접 행렬 만들기¶

    정점이 4개(0~3)이므로 4×4 크기의 2차원 리스트를 만듭니다.

    # 정점 수
n = 4

# 모든 값을 0으로 초기화한 4x4 행렬
matrix = [[0] * n for _ in range(n)]

# 간선 정보 (무방향)
edges = [(0, 1), (0, 2), (1, 2), (2, 3)]

# 간선 추가 - 무방향이므로 양쪽 다 표시
for u, v in edges:
    matrix[u][v] = 1
    matrix[v][u] = 1

# 결과 출력
for row in matrix:
    print(row)

    [0, 1, 1, 0]
[1, 0, 1, 0]
[1, 1, 0, 1]
[0, 0, 1, 0]

    Step 2: 인접 행렬에서 정보 읽기¶

    # 두 정점이 연결되어 있는지 확인
def is_connected_matrix(matrix, a, b):
    return matrix[a][b] == 1

# 특정 정점의 차수 구하기
def degree_matrix(matrix, v):
    return sum(matrix[v])

print(f"0번과 1번 연결? {is_connected_matrix(matrix, 0, 1)}")  # True
print(f"0번과 3번 연결? {is_connected_matrix(matrix, 0, 3)}")  # False
print(f"2번의 차수: {degree_matrix(matrix, 2)}")                # 3

    Step 3: 인접 리스트 만들기¶

    이번에는 딕셔너리를 사용합니다.

    # 빈 인접 리스트 생성
graph = {0: [], 1: [], 2: [], 3: []}

# 간선 정보 (무방향)
edges = [(0, 1), (0, 2), (1, 2), (2, 3)]

# 간선 추가 - 무방향이므로 양쪽 다 추가
for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)

# 결과 출력
for vertex, neighbors in graph.items():
    print(f"정점 {vertex}의 이웃: {neighbors}")

    정점 0의 이웃: [1, 2]
정점 1의 이웃: [0, 2]
정점 2의 이웃: [0, 1, 3]
정점 3의 이웃: [2]

    Step 4: 인접 리스트에서 정보 읽기¶

    # 두 정점이 연결되어 있는지 확인
def is_connected_list(graph, a, b):
    return b in graph[a]

# 특정 정점의 차수 구하기
def degree_list(graph, v):
    return len(graph[v])

print(f"0번과 1번 연결? {is_connected_list(graph, 0, 1)}")  # True
print(f"0번과 3번 연결? {is_connected_list(graph, 0, 3)}")  # False
print(f"2번의 차수: {degree_list(graph, 2)}")                # 3

    Step 5: 가중치 그래프 표현하기¶

    간선에 거리 정보가 있는 경우를 다뤄봅시다.

    # 가중치 그래프 - 인접 리스트 (이웃, 가중치) 튜플로 저장
weighted_graph = {
    "서울": [("대전", 140), ("부산", 325)],
    "대전": [("서울", 140), ("부산", 200)],
    "부산": [("서울", 325), ("대전", 200)]
}

# 서울에서 연결된 도시와 거리 출력
for city, distance in weighted_graph["서울"]:
    print(f"서울 → {city}: {distance}km")

    서울 → 대전: 140km
서울 → 부산: 325km

    Step 6: 방향 그래프 표현하기¶

    팔로우 관계처럼 일방적인 연결을 표현합니다.

    # 방향 그래프 - 한쪽 방향만 추가
follow = {"민수": [], "지영": [], "연예인": []}

# 민수 → 지영 (민수가 지영을 팔로우)
follow["민수"].append("지영")
follow["민수"].append("연예인")
# 지영 → 연예인
follow["지영"].append("연예인")

for person, following in follow.items():
    print(f"{person}의 팔로잉: {following}")

    민수의 팔로잉: ['지영', '연예인']
지영의 팔로잉: ['연예인']
연예인의 팔로잉: []

    📌 알아보기: 방향 그래프에서는 진입 차수(in-degree) 와 진출 차수(out-degree) 를 구분합니다. "연예인"의 진입 차수는 2(민수, 지영이 팔로우), 진출 차수는 0(아무도 팔로우하지 않음)입니다.

    📝 전체 코드¶

    아래는 이번 장에서 다룬 내용을 하나의 파일로 정리한 코드입니다.

    # ============================================
# Chapter 10: 그래프 표현 - 전체 코드
# ============================================

def create_adj_matrix(n, edges, directed=False):
    """인접 행렬 생성"""
    matrix = [[0] * n for _ in range(n)]
    for u, v in edges:
        matrix[u][v] = 1
        if not directed:
            matrix[v][u] = 1
    return matrix

def create_adj_list(n, edges, directed=False):
    """인접 리스트 생성"""
    graph = {i: [] for i in range(n)}
    for u, v in edges:
        graph[u].append(v)
        if not directed:
            graph[v].append(u)
    return graph

def print_matrix(matrix):
    """인접 행렬 출력"""
    print("=== 인접 행렬 ===")
    for row in matrix:
        print(row)

def print_adj_list(graph):
    """인접 리스트 출력"""
    print("=== 인접 리스트 ===")
    for vertex, neighbors in graph.items():
        print(f"  정점 {vertex}: {neighbors}")

def get_degree(graph, v):
    """차수 구하기 (인접 리스트)"""
    return len(graph[v])

def is_connected(graph, a, b):
    """연결 여부 확인 (인접 리스트)"""
    return b in graph[a]

# --- 실행 ---
if __name__ == "__main__":
    n = 4
    edges = [(0, 1), (0, 2), (1, 2), (2, 3)]

    # 인접 행렬
    matrix = create_adj_matrix(n, edges)
    print_matrix(matrix)
    print()

    # 인접 리스트
    graph = create_adj_list(n, edges)
    print_adj_list(graph)
    print()

    # 정보 조회
    print(f"정점 2의 차수: {get_degree(graph, 2)}")
    print(f"0과 3 연결 여부: {is_connected(graph, 0, 3)}")
    print(f"0과 1 연결 여부: {is_connected(graph, 0, 1)}")
    print()

    # 방향 그래프
    print("=== 방향 그래프 ===")
    directed_edges = [(0, 1), (0, 2), (1, 2)]
    d_graph = create_adj_list(n=3, edges=directed_edges, directed=True)
    print_adj_list(d_graph)

    ⚠️ 자주 하는 실수¶

    실수 1: 무방향 그래프에서 한쪽만 추가하기 🔴

    # ❌ 잘못된 코드
for u, v in edges:
    graph[u].append(v)
    # graph[v].append(u)를 빠뜨림!

# ✅ 올바른 코드
for u, v in edges:
    graph[u].append(v)
    graph[v].append(u)  # 양쪽 모두 추가!

    무방향 그래프에서 간선 (0, 1)은 "0→1"과 "1→0" 두 방향 모두 저장해야 합니다. 이걸 빠뜨리면 한쪽에서는 연결이 안 보입니다.

    실수 2: 인접 행렬 초기화를 잘못하기 🔴

    # ❌ 잘못된 코드 - 모든 행이 같은 리스트를 참조!
matrix = [[0] * n] * n

# ✅ 올바른 코드 - 각 행이 독립된 리스트
matrix = [[0] * n for _ in range(n)]

    [[0]*n]*n으로 만들면 한 행을 수정할 때 모든 행이 함께 바뀝니다. 이것은 파이썬에서 리스트 복사의 함정입니다.

    실수 3: 방향 그래프와 무방향 그래프를 혼동하기 🔴

    문제에서 "A가 B를 팔로우한다"는 방향 그래프(A→B만 추가)이고, "A와 B는 친구다"는 무방향 그래프(양쪽 추가)입니다. 문제를 읽을 때 관계의 방향성을 꼭 확인하세요!
