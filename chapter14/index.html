    📖 Chapter 14. 기본 정렬 - 선택 정렬과 삽입 정렬¶

    Part 4 | [2권] 알고리즘의 기초 - 정렬과 탐색

    🎯 이 장에서 배우는 것¶

    • 선택 정렬의 동작 원리를 단계별로 추적하고 파이썬으로 구현할 수 있다
    • 삽입 정렬의 동작 원리를 이해하고 파이썬으로 구현할 수 있다
    • 두 정렬 알고리즘의 차이를 비교하고 각각의 장단점을 설명할 수 있다
    • 두 알고리즘의 시간복잡도가 O(n²)인 이유를 분석할 수 있다

    💡 왜 이걸 배우나요?¶

    여러분이 시험 답안지를 번호순으로 정리하거나, 음악 재생목록을 가나다순으로 정렬하는 상황을 떠올려 보세요. 정렬(Sorting)은 컴퓨터 과학에서 가장 기본이 되는 연산입니다.

    정렬을 배우면 이런 것들이 가능해집니다:

    • 📊 데이터를 빠르게 검색할 수 있는 기반을 만든다
    • 🧠 알고리즘을 단계별로 분석하는 사고력을 기른다
    • ⏱️ "왜 이 방법이 더 빠른가?"를 따져보는 시간복잡도 분석 능력을 얻는다

    선택 정렬과 삽입 정렬은 가장 직관적인 정렬 알고리즘으로, 이후에 배울 고급 정렬(퀵 정렬, 병합 정렬 등)의 출발점이 됩니다.

    📚 핵심 개념¶

    개념 1: 정렬이란?¶

    🃏 비유로 시작

    카드 게임을 할 때 손에 든 카드 5장이 뒤죽박죽이라면? 대부분 숫자 순서대로 다시 배열할 겁니다. 이것이 바로 정렬입니다.

    📐 정확한 정의

    정렬(Sorting): 데이터를 특정 기준(오름차순, 내림차순 등)에 따라 순서대로 재배치하는 작업

    ✏️ 예시로 확인

    • 정렬 전: [64, 25, 12, 22, 11]
    • 오름차순 정렬 후: [11, 12, 22, 25, 64]

    정렬하는 방법(전략)에 따라 다양한 알고리즘이 존재합니다. 오늘은 그중 가장 기초적인 두 가지를 배웁니다.

    개념 2: 선택 정렬 (Selection Sort)¶

    🃏 비유로 시작

    카드 5장이 테이블에 펼쳐져 있다고 상상하세요. 가장 작은 숫자의 카드를 눈으로 찾아서 맨 왼쪽에 놓고, 나머지 중 가장 작은 카드를 그 옆에 놓고… 이 과정을 반복하면 정렬이 완성됩니다.

    📐 정확한 정의

    선택 정렬: 전체 리스트에서 최솟값을 찾아(선택하여) 앞쪽 위치와 교환하는 과정을 반복하는 정렬 알고리즘

    ✏️ 단계별 추적

    리스트 [64, 25, 12, 22, 11]을 오름차순으로 정렬해 봅시다.

    flowchart TD A["초기: [64, 25, 12, 22, 11]"] --> B["1단계: 최솟값 11을 찾아 64와 교환\n→ [11, 25, 12, 22, 64]"] B --> C["2단계: 나머지에서 최솟값 12를 찾아 25와 교환\n→ [11, 12, 25, 22, 64]"] C --> D["3단계: 나머지에서 최솟값 22를 찾아 25와 교환\n→ [11, 12, 22, 25, 64]"] D --> E["4단계: 나머지에서 최솟값 25, 이미 제자리\n→ [11, 12, 22, 25, 64] ✅"]

    💡 알아보기: 원소가 5개이면 4번의 단계만 거치면 됩니다. n개의 원소는 (n-1)번의 단계가 필요합니다.

    개념 3: 삽입 정렬 (Insertion Sort)¶

    🃏 비유로 시작

    이번에는 카드를 한 장씩 받는 상황을 상상하세요. 새 카드를 받을 때마다 이미 정렬된 손패의 알맞은 위치에 끼워넣습니다. 이것이 삽입 정렬의 핵심입니다!

    📐 정확한 정의

    삽입 정렬: 리스트의 각 원소를 이미 정렬된 앞부분의 적절한 위치에 삽입하여 정렬 범위를 넓혀가는 알고리즘

    ✏️ 단계별 추적

    같은 리스트 [64, 25, 12, 22, 11]로 해봅시다.

    flowchart TD A["초기: [64 | 25, 12, 22, 11]\n왼쪽 1개는 이미 정렬됨"] --> B["1단계: 25를 삽입 → 64 앞으로\n→ [25, 64 | 12, 22, 11]"] B --> C["2단계: 12를 삽입 → 25 앞으로\n→ [12, 25, 64 | 22, 11]"] C --> D["3단계: 22를 삽입 → 25 앞, 12 뒤로\n→ [12, 22, 25, 64 | 11]"] D --> E["4단계: 11을 삽입 → 맨 앞으로\n→ [11, 12, 22, 25, 64] ✅"]

    💡 알아보기: | 기호의 왼쪽은 이미 정렬된 부분, 오른쪽은 아직 처리하지 않은 부분입니다. 매 단계마다 정렬된 영역이 하나씩 커집니다.

    개념 4: 시간복잡도 비교¶

    두 알고리즘 모두 O(n²)의 시간복잡도를 가집니다. 하지만 세부적으로는 차이가 있습니다.

    flowchart LR subgraph 선택정렬["🔵 선택 정렬"] S1["비교 횟수: 항상 n×n-1/2"] S2["교환 횟수: 최대 n-1번"] S3["데이터 상태와 무관하게\n항상 같은 시간"] end subgraph 삽입정렬["🟢 삽입 정렬"] I1["비교 횟수: 최악 n×n-1/2"] I2["이동 횟수: 최악 n×n-1/2"] I3["거의 정렬된 데이터에서\n매우 빠름 → O(n)"] end

    🤔 생각해보기: 왜 삽입 정렬은 "거의 정렬된 데이터"에서 빠를까요? 이미 제자리에 가까우면 삽입할 때 비교를 적게 하기 때문입니다! 반면 선택 정렬은 어떤 데이터든 전체를 훑어 최솟값을 찾아야 합니다.

    🔨 따라하기¶

    Step 1: 선택 정렬 함수 작성하기¶

    def selection_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        # 정렬되지 않은 부분에서 최솟값의 인덱스 찾기
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        # 최솟값을 현재 위치와 교환
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

    💡 핵심 포인트: 바깥 for문은 "몇 번째 자리를 채울 것인가", 안쪽 for문은 "나머지 중 최솟값이 어디 있는가"를 담당합니다.

    Step 2: 선택 정렬 과정 시각화하기¶

    매 단계를 출력해서 동작을 눈으로 확인해 봅시다.

    def selection_sort_visual(arr):
    n = len(arr)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:

        arr[i], arr[min_idx] = arr[min_idx], arr[i]
        print(f"  {i+1}단계: {arr}  (인덱스 {i}에 {arr[i]} 배치)")
    return arr

data = [64, 25, 12, 22, 11]
print(f"정렬 전: {data}")
selection_sort_visual(data)
print(f"정렬 후: {data}")

  4단계: [11, 12, 22, 25, 64]  (인덱스 3에 25 배치)
정렬 후: [11, 12, 22, 25, 64]

    Step 3: 삽입 정렬 함수 작성하기¶

    def insertion_sort(arr):
    n = len(arr)
    for i in range(1, n):
        key = arr[i]  # 삽입할 값
        j = i - 1
        # key보다 큰 원소들을 오른쪽으로 밀기
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key  # 빈 자리에 key 삽입
    return arr

    💡 핵심 포인트: key는 지금 삽입하려는 값, while문은 key가 들어갈 자리를 만들기 위해 큰 값들을 한 칸씩 뒤로 미는 과정입니다.

    Step 4: 삽입 정렬 과정 시각화하기¶

    Step 5: 비교 횟수를 세어 두 알고리즘 비교하기¶

    같은 데이터에 두 알고리즘을 적용하고 비교 횟수를 세어봅시다.

    def selection_sort_count(arr):
    arr = arr.copy()
    n = len(arr)
    comparisons = 0
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            comparisons += 1
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr, comparisons

def insertion_sort_count(arr):
    arr = arr.copy()
    n = len(arr)
    comparisons = 0
    for i in range(1, n):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            comparisons += 1
            arr[j + 1] = arr[j]
            j -= 1
        if j >= 0:
            comparisons += 1  # while 탈출 시 마지막 비교
        arr[j + 1] = key
    return arr, comparisons

# 무작위 데이터
data_random = [64, 25, 12, 22, 11]
_, sel_count = selection_sort_count(data_random)
_, ins_count = insertion_sort_count(data_random)
print(f"무작위 데이터 {data_random}")
print(f"  선택 정렬 비교 횟수: {sel_count}")
print(f"  삽입 정렬 비교 횟수: {ins_count}")

# 거의 정렬된 데이터
data_almost = [11, 12, 22, 64, 25]
_, sel_count2 = selection_sort_count(data_almost)
_, ins_count2 = insertion_sort_count(data_almost)
print(f"\n거의 정렬된 데이터 {data_almost}")
print(f"  선택 정렬 비교 횟수: {sel_count2}")
print(f"  삽입 정렬 비교 횟수: {ins_count2}")

    실행 결과:

    무작위 데이터 [64, 25, 12, 22, 11]
  선택 정렬 비교 횟수: 10
  삽입 정렬 비교 횟수: 10

거의 정렬된 데이터 [11, 12, 22, 64, 25]
  선택 정렬 비교 횟수: 10
  삽입 정렬 비교 횟수: 5

    📌 정리하기: 선택 정렬은 데이터 상태와 관계없이 항상 같은 비교 횟수(10회)지만, 삽입 정렬은 거의 정렬된 데이터에서 비교 횟수가 절반으로 줄어듭니다!

    Step 6: 실험 - 데이터 크기에 따른 성능 확인¶

    import random
import time

for n in [1000, 3000, 5000]:
    data = list(range(n))
    random.shuffle(data)

    # 선택 정렬
    arr1 = data.copy()
    start = time.time()
    selection_sort(arr1)
    sel_time = time.time() - start

    # 삽입 정렬
    arr2 = data.copy()
    start = time.time()
    insertion_sort(arr2)
    ins_time = time.time() - start

    print(f"n={n:5d}  선택: {sel_time:.3f}초  삽입: {ins_time:.3f}초")

    🤔 생각해보기: n이 2배가 되면 시간은 약 4배로 늘어납니다. 이것이 바로 O(n²)의 의미입니다!

    📝 전체 코드¶

    아래 코드를 복사해서 실행하면 두 정렬 알고리즘의 동작과 비교를 한눈에 볼 수 있습니다.

    # === 선택 정렬 ===
def selection_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

# === 삽입 정렬 ===
def insertion_sort(arr):
    n = len(arr)
    for i in range(1, n):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr

# === 실행 ===
data = [64, 25, 12, 22, 11]

print("📌 선택 정렬")
result1 = selection_sort(data.copy())
print(f"  결과: {result1}")

print("\n📌 삽입 정렬")
result2 = insertion_sort(data.copy())
print(f"  결과: {result2}")

    실행 결과:

    📌 선택 정렬
  결과: [11, 12, 22, 25, 64]

📌 삽입 정렬
  결과: [11, 12, 22, 25, 64]

    ⚠️ 자주 하는 실수¶

    실수 1: 원본 리스트를 변형하는 것을 모르고 사용하기 🔥

    data = [64, 25, 12, 22, 11]
selection_sort(data)       # data 자체가 변경됨!
print(data)                # [11, 12, 22, 25, 64] ← 원본이 사라짐

    👉 해결: 원본을 보존하려면 selection_sort(data.copy())처럼 복사본을 넘기세요.

    실수 2: 삽입 정렬에서 while 조건 순서 바꾸기 🔥

    # ❌ 잘못된 코드 - 인덱스 오류 발생!
while arr[j] > key and j >= 0:
    ...

# ✅ 올바른 코드 - j >= 0을 먼저 검사!
while j >= 0 and arr[j] > key:
    ...

    👉 이유: j가 -1이 되면 arr[-1]은 리스트의 마지막 원소를 참조하여 잘못된 비교가 일어납니다. j >= 0을 먼저 검사해서 범위를 벗어나지 않도록 해야 합니다. (이것을 단축 평가라고 합니다.)

    실수 3: 선택 정렬에서 값 대신 인덱스를 갱신하지 않기 🔥

    # ❌ 잘못된 코드
min_val = arr[i]
for j in range(i + 1, n):
    if arr[j] < min_val:
        min_val = arr[j]
# 교환하려면 위치(인덱스)를 알아야 하는데 값만 알고 있음!

# ✅ 올바른 코드
min_idx = i                   # 인덱스를 저장
for j in range(i + 1, n):
    if arr[j] < arr[min_idx]:
        min_idx = j           # 인덱스를 갱신
arr[i], arr[min_idx] = arr[min_idx], arr[i]

    👉 핵심: 교환(swap)하려면 위치(인덱스)를 알아야 합니다!

    ✅ 스스로 점검하기¶

    기본 문제¶

    문제 1. 리스트 [29, 10, 14, 37, 13]에 선택 정렬을 적용할 때, 1단계와 2단계 후의 리스트 상태를 적어보세요.

    정답 확인 - **1단계**: 최솟값 10을 찾아 29와 교환 → `[10, 29, 14, 37, 13]` - **2단계**: 나머지 `[29, 14, 37, 13]`에서 최솟값 13을 찾아 29와 교환 → `[10, 13, 14, 37, 29]`

    문제 2. 리스트 [29, 10, 14, 37, 13]에 삽입 정렬을 적용할 때, 1단계와 2단계 후의 리스트 상태를 적어보세요.

    정답 확인 - **1단계**: key=10, 29 뒤에서 앞으로 → `[10, 29, 14, 37, 13]` - **2단계**: key=14, 29 앞에 삽입 → `[10, 14, 29, 37, 13]`

    응용 문제¶

    문제 3. 이미 오름차순으로 정렬된 리스트 [1, 2, 3, 4, 5]에 대해 삽입 정렬의 비교 횟수는 몇 회인가요?

    정답 확인 **4회**입니다. 각 단계에서 key가 바로 앞 원소보다 크므로 `while`문에 들어가지 않고 바깥 비교 1회만 수행합니다. (i=1, 2, 3, 4 → 총 4회) 이것이 삽입 정렬의 **최선의 경우 O(n)**입니다.

    🔗 다음 장으로¶

    📌 정리하기: 이 장에서 배운 핵심 - 선택 정렬: 매번 남은 원소 중 최솟값을 "선택"하여 앞으로 보낸다 - 삽입 정렬: 새 원소를 정렬된 부분의 "적절한 위치에 삽입"한다 - 두 알고리즘 모두 O(n²) 이지만, 거의 정렬된 데이터에서 삽입 정렬이 훨씬 유리하다 - 선택 정렬은 교환 횟수가 적고, 삽입 정렬은 비교 횟수가 적을 수 있다

    지금까지 배운 선택 정렬과 삽입 정렬은 이해하기 쉽지만, 데이터가 많아지면 느려지는 한계가 있습니다. 다음 장에서는 이 한계를 극복하기 위해 "분할 정복" 전략을 사용하는 더 빠른 정렬 알고리즘을 배웁니다. O(n²)에서 O(n log n)으로의 도약, 기대해 주세요! 🚀
