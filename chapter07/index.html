    Chapter 07. 트리 순회 - 트리를 빠짐없이 방문하는 방법¶

    Part 2 | [1권] 비선형 자료구조 - 트리와 히프

    🎯 이 장에서 배우는 것¶

    • 전위·중위·후위·레벨 순회의 방문 순서를 이해하고 구분할 수 있다
    • 재귀 함수를 활용하여 세 가지 순회 알고리즘을 파이썬으로 구현할 수 있다
    • 수식 트리를 예제로 활용하여 순회 방식에 따른 표기법 차이를 확인할 수 있다
    • 레벨 순회(BFS 기반)의 원리를 이해하고 구현할 수 있다

    💡 왜 이걸 배우나요?¶

    도서관에 들어섰다고 상상해 보세요. 수십 개의 서가가 층별로, 구역별로 나뉘어 있습니다. 모든 서가를 빠짐없이 한 번씩 돌아보려면 어떤 순서로 걸어야 할까요?

    "일단 왼쪽 끝부터 쭉 가볼까?" "아니면 층별로 한 바퀴씩 돌까?" — 방법은 여러 가지지만, 한 곳도 빠뜨리지 않는 체계적인 규칙이 필요합니다.

    트리 자료구조도 마찬가지입니다. 트리에 저장된 데이터를 빠짐없이, 정해진 규칙대로 방문하는 것을 순회(Traversal) 라고 합니다. 순회는 트리를 다루는 거의 모든 알고리즘의 기초가 됩니다.

    🔍 알아보기: 파일 탐색기에서 폴더를 열어보는 것, 웹 페이지의 HTML 구조를 분석하는 것, 수식을 계산하는 것 — 이 모든 것이 내부적으로 트리 순회를 사용합니다!

    📚 핵심 개념¶

    개념 1: 순회의 기본 원리 — V, L, R¶

    🏠 비유로 시작

    집을 구경시켜 주는 상황을 떠올려 보세요.

    • 방법 A: 현관(나)을 먼저 설명 → 왼쪽 방 → 오른쪽 방
    • 방법 B: 왼쪽 방 먼저 → 현관(나) 설명 → 오른쪽 방
    • 방법 C: 왼쪽 방 → 오른쪽 방 → 마지막에 현관(나) 설명

    세 방법 모두 빠짐없이 구경하지만, "나(현재 노드)"를 언제 방문하느냐가 다릅니다.

    📖 정확한 정의

    트리 순회에서 각 노드를 방문할 때 세 가지 행동이 있습니다.

    • V (Visit): 현재 노드를 방문(처리)한다
    • L (Left): 왼쪽 서브트리로 이동한다
    • R (Right): 오른쪽 서브트리로 이동한다

    이 세 행동의 순서 조합에 따라 순회 방식이 결정됩니다.

    • 전위 순회 (Preorder): V → L → R (나를 먼저!)
    • 중위 순회 (Inorder): L → V → R (나를 중간에!)
    • 후위 순회 (Postorder): L → R → V (나를 마지막에!)

    ✏️ 예시로 확인

    다음과 같은 간단한 트리를 봅시다.

    graph TD A((A)) --> B((B)) A --> C((C)) B --> D((D)) B --> E((E))
    • 전위(VLR): A → B → D → E → C
    • 중위(LVR): D → B → E → A → C
    • 후위(LRV): D → E → B → C → A

    💡 생각해보기: 세 순회 모두 같은 노드 5개를 방문하지만 순서가 완전히 다릅니다. "V를 언제 처리하느냐"만 기억하면 됩니다!

    개념 2: 재귀로 이해하는 순회¶

    🪆 비유로 시작

    러시아 인형(마트료시카)을 떠올려 보세요. 큰 인형을 열면 작은 인형이 나오고, 그 안에 또 더 작은 인형이 있습니다. 트리 순회도 마찬가지입니다. 하나의 노드를 처리하는 규칙을 정하면, 그 규칙이 자식 노드에도 똑같이 반복 적용됩니다.

    📖 정확한 정의

    재귀(Recursion)란 함수가 자기 자신을 호출하는 프로그래밍 기법입니다. 트리 순회에서 재귀가 자연스러운 이유는 트리 자체가 재귀적 구조이기 때문입니다.

    • 트리 = 루트 노드 + 왼쪽 서브트리(트리) + 오른쪽 서브트리(트리)
    • 서브트리도 트리이므로, 같은 규칙을 반복 적용할 수 있습니다

    ✏️ 전위 순회의 재귀 흐름 추적

    아래 트리에서 전위 순회(VLR)가 어떻게 진행되는지 단계별로 따라가 봅시다.

    graph TD A((A)) --> B((B)) A --> C((C)) B --> D((D)) B --> E((E)) C --> F((F)) C --> G((G))
    1. preorder(A) → 방문 A → preorder(B) 호출
    2. preorder(B) → 방문 B → preorder(D) 호출
    3. preorder(D) → 방문 D → 자식 없음 → 돌아감
    4. preorder(E) → 방문 E → 자식 없음 → 돌아감
    5. preorder(C) → 방문 C → preorder(F) 호출
    6. preorder(F) → 방문 F → 자식 없음 → 돌아감
    7. preorder(G) → 방문 G → 자식 없음 → 끝

    결과: A → B → D → E → C → F → G

    📌 정리하기: 재귀 함수의 종료 조건은 "노드가 None(비어 있음)" 일 때입니다. 이것이 없으면 함수가 무한히 호출되므로 반드시 필요합니다!

    개념 3: 네 가지 순회 방식 비교¶

    flowchart LR subgraph 깊이 우선 A[전위 VLR] B[중위 LVR] C[후위 LRV] end subgraph 너비 우선 D[레벨 순회] end

    앞서 배운 전위·중위·후위 순회는 모두 깊이 우선 탐색(DFS) 방식입니다. 한 방향으로 끝까지 파고든 뒤 돌아옵니다.

    반면 레벨 순회는 너비 우선 탐색(BFS) 방식으로, 트리의 각 층(레벨)을 왼쪽에서 오른쪽으로 차례대로 방문합니다. 도서관을 층별로 한 바퀴씩 도는 것과 같습니다.

    위의 트리(A~G)에서 레벨 순회 결과는:

    레벨 0: A → 레벨 1: B, C → 레벨 2: D, E, F, G

    결과: A → B → C → D → E → F → G

    🔍 알아보기: 레벨 순회는 재귀 대신 큐(Queue) 를 사용합니다. 큐에 넣은 순서대로 꺼내면서 자식을 다시 큐에 넣는 방식입니다.

    개념 4: 수식 트리와 순회의 관계¶

    🧮 비유로 시작

    수학 시간에 배운 (3 + 5) × 2를 트리로 표현할 수 있습니다. 연산자는 부모, 피연산자는 자식이 됩니다.

    graph TD MUL(("×")) --> PLUS(("+")) MUL --> TWO(("2")) PLUS --> THREE(("3")) PLUS --> FIVE(("5"))

    📖 순회 방식에 따른 표기법

    이 수식 트리를 서로 다른 순회로 읽으면 세 가지 수식 표기법이 됩니다.

    • 전위 순회 (VLR): × + 3 5 2 → 전위 표기법(prefix) — 연산자가 앞에
    • 중위 순회 (LVR): 3 + 5 × 2 → 중위 표기법(infix) — 우리가 평소 쓰는 방식
    • 후위 순회 (LRV): 3 5 + 2 × → 후위 표기법(postfix) — 계산기가 좋아하는 방식

    💡 생각해보기: 중위 표기법은 사람이 읽기 편하지만 괄호가 필요합니다. 전위/후위 표기법은 괄호 없이도 연산 순서가 명확합니다. 이것이 컴퓨터가 후위 표기법을 선호하는 이유입니다!

    🔨 따라하기¶

    Step 1: 트리 노드 클래스 만들기¶

    먼저 이진 트리의 노드를 표현하는 클래스를 정의합니다.

    class Node:
    def __init__(self, data, left=None, right=None):
        self.data = data      # 노드에 저장할 데이터
        self.left = left      # 왼쪽 자식 (없으면 None)
        self.right = right    # 오른쪽 자식 (없으면 None)

    Step 2: 예제 트리 구성하기¶

    수식 트리 (3 + 5) × 2를 만들어 봅시다.

    # 리프 노드(잎 노드)부터 만든다
node3 = Node(3)
node5 = Node(5)
node2 = Node(2)

# 내부 노드를 만들면서 자식을 연결한다
plus = Node('+', node3, node5)     # 3 + 5
root = Node('×', plus, node2)      # (3+5) × 2

    Step 3: 전위·중위·후위 순회 구현하기¶

    세 순회의 코드는 딱 한 줄의 위치만 다릅니다!

    def preorder(node):
    """전위 순회: V → L → R"""
    if node is None:
        return
    print(node.data, end=' ')   # V: 방문
    preorder(node.left)          # L: 왼쪽
    preorder(node.right)         # R: 오른쪽

def inorder(node):
    """중위 순회: L → V → R"""
    if node is None:
        return
    inorder(node.left)           # L: 왼쪽
    print(node.data, end=' ')   # V: 방문
    inorder(node.right)          # R: 오른쪽

def postorder(node):
    """후위 순회: L → R → V"""
    if node is None:
        return
    postorder(node.left)         # L: 왼쪽
    postorder(node.right)        # R: 오른쪽
    print(node.data, end=' ')   # V: 방문

    📌 정리하기: print 문(V)의 위치만 바꾸면 됩니다. 위에 있으면 전위, 중간이면 중위, 아래면 후위!

    Step 4: 실행하고 결과 확인하기¶

    print("전위 순회:", end=' ')
preorder(root)
print()

print("중위 순회:", end=' ')
inorder(root)
print()

print("후위 순회:", end=' ')
postorder(root)
print()

    실행 결과: 

    전위 순회: × + 3 5 2
중위 순회: 3 + 5 × 2
후위 순회: 3 5 + 2 ×

    Step 5: 레벨 순회 구현하기 (큐 활용)¶

    from collections import deque

def level_order(node):
    """레벨 순회: 층별로 왼쪽→오른쪽"""
    if node is None:
        return
    queue = deque()
    queue.append(node)           # 루트를 큐에 넣는다

    while queue:
        current = queue.popleft()  # 큐에서 하나 꺼낸다
        print(current.data, end=' ')

        if current.left:           # 왼쪽 자식이 있으면 큐에 추가
            queue.append(current.left)
        if current.right:          # 오른쪽 자식이 있으면 큐에 추가
            queue.append(current.right)

    print("레벨 순회:", end=' ')
level_order(root)
print()

    실행 결과: 

    레벨 순회: × + 2 3 5

    Step 6: 결과를 리스트로 반환하는 버전¶

    실무에서는 출력 대신 리스트로 모아서 반환하는 것이 더 유용합니다.

    def preorder_list(node):
    """전위 순회 결과를 리스트로 반환"""
    if node is None:
        return []
    return [node.data] + preorder_list(node.left) + preorder_list(node.right)

# 테스트
print(preorder_list(root))  # ['×', '+', 3, 5, 2]

    💡 중위, 후위도 같은 패턴으로 리스트 합치는 순서만 바꾸면 됩니다!

    📝 전체 코드¶

    아래 코드를 복사하여 바로 실행할 수 있습니다.

    from collections import deque

# ── 노드 클래스 ──
class Node:
    def __init__(self, data, left=None, right=None):
        self.data = data
        self.left = left
        self.right = right

# ── 순회 함수 ──
def preorder(node):
    if node is None:
        return
    print(node.data, end=' ')
    preorder(node.left)
    preorder(node.right)

def inorder(node):
    if node is None:
        return
    inorder(node.left)
    print(node.data, end=' ')
    inorder(node.right)

def postorder(node):
    if node is None:
        return
    postorder(node.left)
    postorder(node.right)
    print(node.data, end=' ')

def level_order(node):
    if node is None:
        return
    queue = deque()
    queue.append(node)
    while queue:
        current = queue.popleft()
        print(current.data, end=' ')
        if current.left:
            queue.append(current.left)
        if current.right:
            queue.append(current.right)

# ── 수식 트리 만들기: (3 + 5) × 2 ──
node3 = Node(3)
node5 = Node(5)
node2 = Node(2)
plus = Node('+', node3, node5)
root = Node('×', plus, node2)

    ⚠️ 자주 하는 실수¶

    실수 1: 종료 조건을 빠뜨린다 🔴

    # ❌ 잘못된 코드 - 종료 조건 없음
def preorder(node):
    print(node.data, end=' ')  # node가 None이면 에러 발생!
    preorder(node.left)
    preorder(node.right)

# ✅ 올바른 코드
def preorder(node):
    if node is None:           # 반드시 종료 조건 먼저!
        return
    print(node.data, end=' ')
    preorder(node.left)
    preorder(node.right)

    None인 노드에 .data를 접근하면 AttributeError가 발생합니다. 재귀 함수의 첫 줄은 항상 종료 조건!

    실수 2: V의 위치를 헷갈린다 🔴

    "후위 순회인데 print를 맨 위에 썼어요" — 이러면 전위 순회가 되어 버립니다.

    🎯 외우는 팁: 전위 = print가 전방(맨 위), 후위 = print가 후방(맨 아래), 중위 = print가 중간

    실수 3: 레벨 순회에서 스택을 사용한다 🔴

    레벨 순회는 큐(FIFO) 를 사용해야 합니다. 스택(LIFO)을 사용하면 방문 순서가 뒤섞입니다.

    # ❌ 잘못: 리스트를 스택처럼 사용 (pop()은 뒤에서 꺼냄)
current = queue.pop()

# ✅ 올바름: 큐처럼 앞에서 꺼냄
current = queue.popleft()

    실수 4: 왼쪽/오른쪽 자식 순서를 바꾼다 🔴

    # ❌ 오른쪽을 먼저 방문하면 결과가 달라짐
preorder(node.right)
preorder(node.left)

    순회의 정의에서 L은 항상 R보다 먼저입니다. 순서를 바꾸면 전혀 다른 결과가 나옵니다.

    ✅ 스스로 점검하기¶

    기본 문제¶

    문제 1. 아래 트리의 전위·중위·후위 순회 결과를 각각 적어 보세요.

    graph TD H((H)) --> D((D)) H --> K((K)) D --> B((B)) D --> F((F)) K --> J((J))

    💡 힌트: K의 오른쪽 자식은 없습니다. J는 K의 왼쪽 자식입니다.

    정답 보기 - **전위**: H → D → B → F → K → J - **중위**: B → D → F → H → J → K - **후위**: B → F → D → J → K → H

    문제 2. 다음 중 후위 순회의 방문 순서는? - (a) V → L → R - (b) L → V → R - (c) L → R → V - (d) R → L → V

    정답 보기 **(c) L → R → V** — 후위 순회는 왼쪽, 오른쪽을 모두 방문한 뒤 자신을 마지막에 처리합니다.

    응용 문제¶

    문제 3. 수식 (7 - 1) / (4 + 2)를 수식 트리로 그린 뒤, 전위·후위 순회 결과를 적어 보세요.

    정답 보기 수식 트리:
    graph TD DIV(("/")) --> MINUS(("-")) DIV --> PLUS2(("+")) MINUS --> SEVEN(("7")) MINUS --> ONE(("1")) PLUS2 --> FOUR(("4")) PLUS2 --> TWO(("2"))
    - **전위**: / - 7 1 + 4 2 - **후위**: 7 1 - 4 2 + /

    심화 문제¶

    문제 4. 어떤 트리의 중위 순회 결과가 D B E A F C이고, 전위 순회 결과가 A B D E C F일 때, 이 트리의 구조를 복원해 보세요.

    풀이 힌트 전위 순회의 **첫 번째 원소**는 항상 루트입니다. 중위 순회에서 루트를 기준으로 왼쪽/오른쪽을 나눌 수 있습니다. 1. 전위 첫 원소 = A(루트) 2. 중위에서 A 기준: 왼쪽 `D B E` / 오른쪽 `F C` 3. 왼쪽 서브트리의 전위 = `B D E` → 루트는 B 4. 이 과정을 재귀적으로 반복!
    정답 보기
    graph TD A((A)) --> B((B)) A --> C((C)) B --> D((D)) B --> E((E)) C --> F((F))
    C의 왼쪽 자식이 F이고, 오른쪽 자식은 없습니다.
