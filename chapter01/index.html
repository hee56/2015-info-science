    Chapter 01. 자료구조를 왜 배울까? - 워밍업과 함수 복습¶

    Part 1 | [1권] 자료구조의 기초 - 순차 자료구조와 연결 자료구조

    🎯 이 장에서 배우는 것¶

    • 자료구조가 무엇인지 자신의 말로 설명할 수 있다
    • 자료구조를 배워야 하는 이유를 실생활 예시와 연결지어 말할 수 있다
    • 파이썬 함수를 정의하고, 매개변수와 반환값을 활용할 수 있다
    • 앞으로 배울 자료구조의 전체 로드맵을 파악할 수 있다

    💡 왜 이걸 배우나요?¶

    생각해보기 🤔

    친구의 전화번호 10개를 종이에 적어두었습니다. 이름순으로 정리하지 않고 아무렇게나 적었다면, 특정 친구의 번호를 찾을 때 어떻게 해야 할까요? 100개라면? 10,000개라면?

    전화번호가 10개일 때는 위에서 아래로 쭉 훑어보면 됩니다. 하지만 10,000개라면 이야기가 달라집니다. 가나다순으로 정리해 두었다면 단번에 원하는 이름 근처로 점프할 수 있겠죠.

    이것이 바로 자료구조의 핵심입니다. 같은 데이터라도 어떻게 정리하느냐에 따라 찾고, 추가하고, 삭제하는 속도가 완전히 달라집니다.

    프로그래밍도 마찬가지입니다. 데이터를 효율적으로 저장하고 꺼내 쓰는 방법을 모르면, 코드가 느려지거나 복잡해집니다. 자료구조를 배우면 "어떤 상황에서 어떤 정리법을 쓸까?" 라는 질문에 스스로 답할 수 있게 됩니다.

    📚 핵심 개념¶

    개념 1: 자료구조란 무엇인가?¶

    1. 비유로 시작 🏠

    집에 물건을 보관하는 방법을 떠올려 보세요.

    • 옷장: 옷을 종류별로 칸칸이 넣어둡니다 → 꺼낼 때 빠릅니다
    • 서랍 없는 방바닥: 모든 물건이 뒤섞여 있습니다 → 찾는 데 오래 걸립니다

    프로그래밍에서 데이터는 "물건"이고, 자료구조는 그 물건을 담는 "옷장의 설계도" 입니다.

    2. 정확한 정의 📖

    자료구조(Data Structure)란 데이터를 효율적으로 저장, 관리, 접근하기 위해 데이터를 특정 형태로 조직하는 방법입니다.

    3. 예시로 확인 ✅

    일상에서 이미 자료구조를 쓰고 있습니다.

    • 대기번호표 → 먼저 온 사람이 먼저 나감 → "큐(Queue)"
    • 접시 쌓기 → 마지막에 올린 접시를 먼저 꺼냄 → "스택(Stack)"
    • 가계도 → 부모-자식 관계가 뻗어나감 → "트리(Tree)"

    개념 2: 자료구조의 분류 — 선형과 비선형¶

    1. 비유로 시작 🚂

    • 선형(Linear): 기차처럼 데이터가 한 줄로 연결된 구조
    • 비선형(Non-linear): 지하철 노선도처럼 데이터가 여러 갈래로 뻗는 구조

    2. 정확한 정의 📖

    • 선형 자료구조: 데이터 요소들이 순서대로 일렬 배치. 하나의 원소 뒤에 하나의 원소만 존재
    • 비선형 자료구조: 데이터 요소들이 계층적이거나 망(network) 형태로 연결

    3. 다이어그램으로 확인

    graph LR subgraph 선형 자료구조 A1[배열] --- A2[연결 리스트] --- A3[스택] --- A4[큐] end subgraph 비선형 자료구조 B1[트리] --- B2[그래프] end

    알아보기 📌

    이 교재에서는 1권에서 선형 자료구조(배열, 연결 리스트, 스택, 큐)를, 2권에서 비선형 자료구조(트리, 그래프)와 정렬·탐색을 다룹니다.

    개념 3: 전체 로드맵 미리보기¶

    앞으로 20차시에 걸쳐 배울 내용을 한눈에 살펴봅시다.

    graph TD C1["1차시<br/>자료구조 소개 & 함수 복습<br/>⬅ 지금 여기!"] C2["2~4차시<br/>배열과 리스트"] C3["5~7차시<br/>스택"] C4["8~10차시<br/>큐"] C5["11~14차시<br/>연결 리스트"] C6["15~17차시<br/>트리"] C7["18~20차시<br/>그래프 & 정렬/탐색"] C1 --> C2 --> C3 --> C4 --> C5 --> C6 --> C7

    각 자료구조를 배울 때마다 직접 파이썬 코드로 구현합니다. 그래서 지금부터 파이썬 함수 문법을 탄탄히 복습해 두어야 합니다.

    개념 4: 파이썬 함수 복습¶

    자료구조를 코드로 만들 때, 함수(function) 는 가장 기본적인 도구입니다.

    1. 비유로 시작 🧃

    자판기를 떠올려 보세요. 동전(입력) 을 넣으면, 내부에서 처리가 일어나고, 음료(출력) 가 나옵니다. 함수도 동일합니다.

    • 매개변수(Parameter) = 동전 투입구 (입력을 받는 통로)
    • 함수 본문 = 자판기 내부 동작 (처리)
    • 반환값(return) = 음료가 나오는 출구 (결과를 돌려줌)

    2. 정확한 문법 📖

    def 함수이름(매개변수1, 매개변수2):
    """함수가 하는 일을 설명하는 문서화 문자열"""
    # 처리 로직
    return 결과값

    핵심 키워드 정리:

    • def: "이제부터 함수를 정의(define)하겠다"는 선언
    • 매개변수(parameter): 함수가 외부에서 받아들이는 값의 이름표
    • return: 함수의 실행 결과를 호출한 곳으로 돌려보냄
    • 기본값 인자(default argument): 매개변수에 미리 값을 지정해 두어 호출 시 생략 가능하게 함

    3. 예시로 확인 ✅

    # 두 수를 더하는 함수
def add(a, b):
    return a + b

result = add(3, 5)
print(result)  # 8

    # 기본값 인자 예시: 인사 함수
def greet(name, greeting="안녕하세요"):
    return f"{greeting}, {name}님!"

print(greet("지민"))             # 안녕하세요, 지민님!
print(greet("지민", "반갑습니다"))  # 반갑습니다, 지민님!

    정리하기 📋

    • 함수 = 입력 → 처리 → 출력 의 재사용 가능한 코드 덩어리
    • def로 정의하고, return으로 결과를 돌려준다
    • 기본값 인자를 쓰면 호출할 때 인자를 생략할 수 있다

    🔨 따라하기¶

    목표: 리스트에서 최댓값을 찾는 함수를 단계별로 직접 만들어 봅시다.

    Step 1: 빈 함수 뼈대 만들기¶

    먼저 함수의 틀만 잡습니다. 아직 내부 로직은 비워둡니다.

    def find_max(numbers):
    """리스트에서 가장 큰 값을 반환하는 함수"""
    pass  # 아직 구현 전

    알아보기 📌

    pass는 "아직 내용이 없다"는 뜻의 자리표시자입니다. 함수 뼈대를 먼저 잡고 나중에 채우는 습관을 들이면, 구조를 먼저 생각하게 되어 코딩이 수월해집니다.

    Step 2: 첫 번째 값을 기준으로 설정하기¶

    리스트의 첫 번째 값을 현재 최댓값으로 잡습니다.

    def find_max(numbers):
    """리스트에서 가장 큰 값을 반환하는 함수"""
    current_max = numbers[0]  # 첫 번째 값을 기준으로
    return current_max

    print(find_max([3, 7, 2]))  # 3 (아직 비교를 안 했으니 첫 값만 나옴)

    Step 3: 반복문으로 비교하기¶

    리스트의 나머지 값들을 하나씩 비교하면서 더 큰 값이 있으면 갱신합니다.

    def find_max(numbers):
    """리스트에서 가장 큰 값을 반환하는 함수"""
    current_max = numbers[0]

    for num in numbers[1:]:    # 두 번째 원소부터 끝까지
        if num > current_max:  # 현재 최댓값보다 크면
            current_max = num  # 갱신!

    return current_max

    print(find_max([3, 7, 2]))      # 7 ✅
print(find_max([10, 5, 8, 12])) # 12 ✅

    Step 4: 빈 리스트 예외 처리 추가하기¶

    만약 빈 리스트가 들어오면 numbers[0]에서 에러가 납니다. 이를 미리 막아봅시다.

    def find_max(numbers):
    """리스트에서 가장 큰 값을 반환하는 함수"""
    if len(numbers) == 0:
        return None  # 빈 리스트이면 None 반환

    current_max = numbers[0]

    for num in numbers[1:]:
        if num > current_max:
            current_max = num

    return current_max

    print(find_max([]))  # None (에러 없이 안전하게 처리)

    생각해보기 🤔

    이 과정이 바로 자료구조를 배울 때의 사고방식입니다. 1. 뼈대를 먼저 잡고 → 2. 핵심 로직을 채우고 → 3. 예외 상황을 처리한다. 앞으로 스택, 큐, 연결 리스트를 만들 때도 이 순서를 반복합니다!

    📝 전체 코드¶

    아래 코드를 복사해서 그대로 실행해 볼 수 있습니다.

    # ============================================
# Chapter 01: 워밍업 - 함수 복습과 활용
# ============================================

# --- 1. 기본 함수: 두 수 더하기 ---
def add(a, b):
    """두 수를 더한 결과를 반환한다."""
    return a + b

# --- 2. 기본값 인자가 있는 함수: 인사 ---
def greet(name, greeting="안녕하세요"):
    """이름과 인사말을 조합하여 반환한다."""
    return f"{greeting}, {name}님!"

# --- 3. 리스트에서 최댓값 찾기 ---
def find_max(numbers):
    """리스트에서 가장 큰 값을 반환한다.
    빈 리스트이면 None을 반환한다."""
    if len(numbers) == 0:
        return None

    current_max = numbers[0]

    for num in numbers[1:]:
        if num > current_max:
            current_max = num

    return current_max

# === 실행 테스트 ===
if __name__ == "__main__":
    # 1. add 테스트
    print("=== 두 수 더하기 ===")
    print(f"add(3, 5) = {add(3, 5)}")          # 8
    print(f"add(10, -3) = {add(10, -3)}")      # 7

    # 2. greet 테스트
    print("\n=== 인사하기 ===")
    print(greet("지민"))                         # 안녕하세요, 지민님!
    print(greet("지민", "반갑습니다"))             # 반갑습니다, 지민님!

    # 3. find_max 테스트
    print("\n=== 최댓값 찾기 ===")
    print(f"find_max([3, 7, 2]) = {find_max([3, 7, 2])}")          # 7
    print(f"find_max([10, 5, 8, 12]) = {find_max([10, 5, 8, 12])}")  # 12
    print(f"find_max([]) = {find_max([])}")                          # None
    print(f"find_max([42]) = {find_max([42])}")                      # 42

    실행 결과:

    === 두 수 더하기 ===
add(3, 5) = 8
add(10, -3) = 7

    실수 1: return을 빼먹는다¶

    # ❌ 잘못된 코드
def add(a, b):
    a + b       # return이 없으면 결과가 사라진다!

result = add(3, 5)
print(result)   # None 😱

    # ✅ 올바른 코드
def add(a, b):
    return a + b  # 반드시 return으로 돌려주어야 한다

result = add(3, 5)
print(result)   # 8 ✅

    return이 없으면 함수는 자동으로 None을 반환합니다. 계산은 했지만 결과를 돌려주지 않는 것이니 꼭 확인하세요!

    실수 2: 기본값 인자를 앞에 배치한다¶

    # ❌ 문법 오류 발생
def greet(greeting="안녕", name):
    return f"{greeting}, {name}님!"
# SyntaxError! 기본값이 있는 매개변수는 반드시 뒤에 와야 한다

    # ✅ 올바른 코드
def greet(name, greeting="안녕"):
    return f"{greeting}, {name}님!"

    규칙: 기본값이 없는 매개변수가 먼저, 기본값이 있는 매개변수가 뒤에 와야 합니다.

    실수 3: 빈 리스트 처리를 잊는다¶

    # ❌ 빈 리스트를 넣으면 에러
def find_max(numbers):
    current_max = numbers[0]  # IndexError: list index out of range
    for num in numbers[1:]:
        if num > current_max:
            current_max = num
    return current_max

find_max([])  # 💥 에러!

    자료구조를 다룰 때 "데이터가 없는 경우" 를 항상 먼저 생각하세요. 이것은 앞으로 스택, 큐 등을 구현할 때도 반복되는 핵심 패턴입니다.

    💡 힌트: 파이썬에서는 return 값1, 값2로 여러 값을 한 번에 반환할 수 있습니다.

    # 여기에 코드를 작성하세요
    pass

# 테스트

    정답 보기 
    def find_min_max(numbers):
    if len(numbers) == 0:
        return None, None

    current_min = numbers[0]
    current_max = numbers[0]

    for num in numbers[1:]:
        if num < current_min:
            current_min = num
        if num > current_max:
            current_max = num

    return current_min, current_max
    한 번의 반복문으로 최솟값과 최댓값을 동시에 구합니다. 리스트를 한 바퀴만 도는 것이 두 바퀴 도는 것보다 효율적이죠? 이런 **효율성에 대한 감각**이 바로 자료구조를 배우는 이유입니다!
