    Chapter 05. 덱과 우선순위 큐 - 큐의 변신¶

    Part 1 | [1권] 자료구조의 기초 - 순차 자료구조와 연결 자료구조

    🎯 이 장에서 배우는 것¶

    • 덱(Deque)의 구조를 이해하고 양쪽 끝에서 삽입·삭제를 수행할 수 있다
    • 우선순위 큐의 개념을 이해하고 heapq로 구현할 수 있다
    • 힙(Heap)의 기본 원리를 설명할 수 있다
    • 스택·큐·덱·우선순위 큐 중 상황에 맞는 자료구조를 선택할 수 있다

    💡 왜 이걸 배우나요?¶

    앞 장에서 배운 스택은 한쪽 끝만, 큐는 한쪽에서 넣고 반대쪽에서 꺼내는 구조였습니다. 하지만 현실 세계에는 이 두 가지만으로 해결하기 어려운 상황이 많습니다.

    🤔 생각해보기: 웹 브라우저의 "최근 방문 기록"은 새 페이지가 앞에 추가되고, 오래된 기록은 뒤에서 제거됩니다. 스택? 큐? 둘 다 아닙니다!

    🤔 생각해보기: 응급실에서는 먼저 온 환자가 아니라 더 위급한 환자가 먼저 치료받습니다. 일반 큐로는 이 상황을 표현할 수 없습니다.

    이번 장에서는 큐가 두 가지 방향으로 변신한 자료구조를 배웁니다.

    • 덱(Deque): 양쪽 끝 모두에서 넣고 뺄 수 있는 구조
    • 우선순위 큐(Priority Queue): 우선순위가 높은 것이 먼저 나오는 구조

    이 둘을 익히면, 여러분은 네 가지 핵심 선형 자료구조(스택, 큐, 덱, 우선순위 큐)를 모두 활용할 수 있게 됩니다. 🎉

    📚 핵심 개념¶

    개념 1: 덱(Deque) — 양쪽 문이 있는 통로¶

    ① 비유로 시작

    양쪽에 문이 달린 지하철 통로를 상상해 보세요. 사람은 왼쪽 문으로도, 오른쪽 문으로도 들어오고 나갈 수 있습니다. 스택은 문이 하나, 큐는 입구와 출구가 고정되어 있지만, 덱은 양쪽 모두 입구이자 출구입니다.

    ② 정확한 정의

    덱(Deque, Double-Ended Queue) 은 양쪽 끝(front와 rear)에서 삽입과 삭제가 모두 가능한 자료구조입니다. 스택과 큐의 기능을 동시에 수행할 수 있는 일반화된 구조입니다.

    flowchart LR subgraph Deque direction LR A["앞(front)"] --- B["요소1"] --- C["요소2"] --- D["요소3"] --- E["뒤(rear)"] end F["삽입/삭제 ↔"] --> A E --> G["↔ 삽입/삭제"]

    ③ 예시로 확인 — 덱의 주요 연산

    파이썬 collections.deque가 제공하는 핵심 연산은 네 가지입니다.

    • append(x) — 뒤(rear)에 삽입
    • appendleft(x) — 앞(front)에 삽입
    • pop() — 뒤(rear)에서 삭제 후 반환
    • popleft() — 앞(front)에서 삭제 후 반환

    📌 알아보기: 파이썬 리스트도 append와 pop은 빠르지만, insert(0, x)나 pop(0)은 모든 요소를 이동시켜야 해서 O(n) 입니다. 반면 deque의 네 연산은 모두 O(1) 입니다. 이것이 deque를 사용하는 핵심 이유입니다!

    개념 2: 덱의 활용 — 스택도 되고 큐도 되고¶

    덱은 사용 방법에 따라 다른 자료구조처럼 동작합니다.

    • 큐처럼 사용: append()로 넣고 popleft()로 꺼내기 (FIFO)
    • 스택처럼 사용: append()로 넣고 pop()으로 꺼내기 (LIFO)
    • 덱 고유 기능: 양쪽 모두 자유롭게 삽입·삭제
    flowchart TD DEQUE["🔄 덱(Deque)"] STACK["스택처럼 사용\nappend + pop"] QUEUE["큐처럼 사용\nappend + popleft"] BOTH["양쪽 자유\nappendleft + pop 등"] DEQUE --> STACK DEQUE --> QUEUE DEQUE --> BOTH

    📌 알아보기: deque(maxlen=N)처럼 최대 길이를 지정하면, 한쪽에 요소가 추가될 때 반대쪽의 오래된 요소가 자동으로 제거됩니다. "최근 N개만 유지"하는 기능에 딱 맞습니다!

    개념 3: 우선순위 큐 — 응급실의 원리¶

    ① 비유로 시작

    응급실에서는 접수 순서가 아니라 중증도에 따라 치료 순서가 결정됩니다. 가벼운 찰과상 환자가 먼저 왔더라도, 심정지 환자가 오면 그 환자가 먼저 치료실에 들어갑니다.

    ② 정확한 정의

    우선순위 큐(Priority Queue) 는 각 요소가 우선순위(priority) 를 가지며, 꺼낼 때 항상 우선순위가 가장 높은 요소가 먼저 나오는 자료구조입니다.

    일반 큐와의 차이를 정리하면 이렇습니다.

    • 일반 큐: 먼저 들어온 것이 먼저 나감 (FIFO)
    • 우선순위 큐: 우선순위가 높은 것이 먼저 나감

    ③ 예시로 확인

    파이썬 heapq 모듈은 최소 힙(min-heap) 을 구현합니다. 숫자가 작을수록 우선순위가 높습니다.

    • heapq.heappush(heap, item) — 우선순위를 유지하면서 삽입
    • heapq.heappop(heap) — 가장 작은(우선순위 높은) 요소를 꺼냄
    import heapq

# 응급실 환자: (중증도 숫자가 낮을수록 위급)
patients = []
heapq.heappush(patients, (3, "찰과상 환자"))
heapq.heappush(patients, (1, "심정지 환자"))
heapq.heappush(patients, (2, "골절 환자"))

# 꺼내는 순서: 중증도 1 → 2 → 3
print(heapq.heappop(patients))  # (1, '심정지 환자')
print(heapq.heappop(patients))  # (2, '골절 환자')
print(heapq.heappop(patients))  # (3, '찰과상 환자')

    개념 4: 힙(Heap) — 우선순위 큐의 비밀 엔진¶

    ① 비유로 시작

    토너먼트 대진표를 떠올려 보세요. 가장 강한 선수가 항상 꼭대기에 위치합니다. 새 선수가 참가하면 아래에서 위로 올라가며 자기 자리를 찾고, 우승자가 빠지면 아래에서 다음 강자가 올라옵니다.

    ② 정확한 정의

    힙(Heap) 은 완전 이진 트리 형태이면서, 부모 노드가 항상 자식 노드보다 작은(최소 힙) 또는 큰(최대 힙) 값을 가지는 자료구조입니다.

    flowchart TD A["1 (루트 = 최솟값)"] --> B["3"] A --> C["2"] B --> D["7"] B --> E["4"] C --> F["5"] style A fill:#ff6b6b,color:#fff

    핵심 특징은 이렇습니다.

    • 삽입: 맨 끝에 넣고, 부모와 비교하며 위로 올림 → O(log n)
    • 삭제: 루트를 꺼내고, 맨 끝 요소를 루트에 놓은 뒤 아래로 내림 → O(log n)
    • 리스트를 정렬해서 매번 최솟값을 찾는 것(O(n))보다 훨씬 빠릅니다!

    ③ 예시로 확인 — 배열로 표현하는 힙

    힙은 배열(리스트)로 표현됩니다. 인덱스 i의 노드에 대해 부모는 (i-1)//2, 왼쪽 자식은 2*i+1, 오른쪽 자식은 2*i+2입니다.

    📌 정리하기: heapq는 내부적으로 이 배열 기반 힙을 사용합니다. 별도의 트리 구조를 만들 필요 없이 일반 리스트를 힙으로 관리해 줍니다.

    🔨 따라하기¶

    Step 1: 덱 기본 조작 — 양쪽에서 넣고 빼기¶

    from collections import deque

# 빈 덱 생성
dq = deque()

# 뒤에 추가
dq.append(1)
dq.append(2)
dq.append(3)
print("초기 상태:", dq)  # deque([1, 2, 3])

# 앞에 추가
dq.appendleft(0)
print("앞에 0 추가:", dq)  # deque([0, 1, 2, 3])

# 뒤에서 제거
rear = dq.pop()
print(f"뒤에서 꺼냄: {rear}, 덱: {dq}")  # 3, deque([0, 1, 2])

# 앞에서 제거
front = dq.popleft()
print(f"앞에서 꺼냄: {front}, 덱: {dq}")  # 0, deque([1, 2])

    Step 2: 최근 N개 기록 유지 — maxlen 활용¶

    from collections import deque

# 최근 3개 방문 기록만 유지
history = deque(maxlen=3)

pages = ["네이버", "구글", "유튜브", "깃허브", "위키피디아"]
for page in pages:
    history.append(page)
    print(f"방문: {page} → 기록: {list(history)}")

    실행하면 항상 최근 3개만 남는 것을 확인할 수 있습니다.

    방문: 네이버 → 기록: ['네이버']
방문: 구글 → 기록: ['네이버', '구글']
방문: 유튜브 → 기록: ['네이버', '구글', '유튜브']
방문: 깃허브 → 기록: ['구글', '유튜브', '깃허브']
방문: 위키피디아 → 기록: ['유튜브', '깃허브', '위키피디아']

    Step 3: 회문(팰린드롬) 검사 — 덱의 실전 활용¶

    "토마토"처럼 앞에서 읽으나 뒤에서 읽으나 같은 단어를 회문이라 합니다. 덱의 양쪽 꺼내기가 딱 맞는 문제입니다.

    from collections import deque

def is_palindrome(word):
    dq = deque(word)
    while len(dq) > 1:
        if dq.popleft() != dq.pop():
            return False
    return True

print(is_palindrome("토마토"))  # True
print(is_palindrome("기러기"))  # True
print(is_palindrome("파이썬"))  # False

    📌 알아보기: 앞과 뒤에서 동시에 한 글자씩 비교하므로, 반복 횟수가 절반으로 줄어듭니다. 덱의 양방향 특성을 잘 활용한 예시입니다.

    Step 4: 우선순위 큐 기본 — heapq 사용¶

    import heapq

# 빈 힙(일반 리스트)
task_queue = []

# 작업 추가: (우선순위, 작업명)
heapq.heappush(task_queue, (2, "보고서 작성"))
heapq.heappush(task_queue, (1, "버그 수정"))
heapq.heappush(task_queue, (3, "회의 참석"))

print("힙 내부 상태:", task_queue)

# 우선순위 순서로 꺼내기
while task_queue:
    priority, task = heapq.heappop(task_queue)
    print(f"  처리: [{priority}] {task}")

    힙 내부 상태: [(1, '버그 수정'), (2, '보고서 작성'), (3, '회의 참석')]
  처리: [1] 버그 수정
  처리: [2] 보고서 작성
  처리: [3] 회의 참석

    Step 5: 최대 힙 — 우선순위 뒤집기¶

    heapq는 최소 힙만 지원합니다. 큰 값을 먼저 꺼내려면 부호를 뒤집는 트릭을 사용합니다.

    import heapq

scores = [85, 92, 78, 95, 88]
max_heap = []

# 음수로 넣기
for s in scores:
    heapq.heappush(max_heap, -s)

# 꺼낼 때 부호 복원
print("성적 높은 순:")
while max_heap:
    print(f"  {-heapq.heappop(max_heap)}점")

    성적 높은 순:
  95점
  92점
  88점
  85점
  78점

    Step 6: 네 가지 자료구조 비교 정리¶

    지금까지 배운 자료구조를 한눈에 비교해 봅시다.

    flowchart LR subgraph 비교["📊 자료구조 비교"] direction TB S["🥞 스택\n한쪽 끝 삽입·삭제\nLIFO\nO(1)"] Q["🚶 큐\n뒤에서 삽입, 앞에서 삭제\nFIFO\nO(1)"] D["🚪 덱\n양쪽 삽입·삭제\nFIFO+LIFO\nO(1)"] P["🏥 우선순위 큐\n아무 데서 삽입, 최우선 삭제\n우선순위 순\nO(log n)"] end
    • 스택 🥞 — 삽입·삭제가 한쪽 끝(top)에서만 일어남, LIFO, 연산 O(1)
    • 큐 🚶 — 뒤에서 삽입(enqueue), 앞에서 삭제(dequeue), FIFO, 연산 O(1)
    • 덱 🚪 — 양쪽 끝에서 삽입·삭제 모두 가능, FIFO+LIFO 겸용, 연산 O(1)
    • 우선순위 큐 🏥 — 우선순위가 가장 높은 요소가 먼저 나옴, 삽입·삭제 O(log n)

    📌 정리하기: 덱은 스택과 큐를 일반화한 것이고, 우선순위 큐는 큐의 꺼내는 순서를 우선순위 기반으로 바꾼 것입니다. 목적에 맞는 자료구조를 선택하는 것이 핵심입니다!

    📝 전체 코드¶

    아래는 이번 장의 핵심을 하나로 모은 종합 예제입니다. 복사해서 바로 실행해 보세요.

    """
Chapter 05 - 덱과 우선순위 큐 종합 예제
: 작업 스케줄링 시뮬레이션
"""
from collections import deque
import heapq

# === 1. 덱: 양방향 작업 대기열 ===
print("=" * 40)
print("🚪 덱 - 양방향 작업 대기열")
print("=" * 40)

work_queue = deque()

# 일반 작업은 뒤에 추가
work_queue.append("일반 작업 A")
work_queue.append("일반 작업 B")
print(f"일반 작업 추가 후: {list(work_queue)}")

# 긴급 작업은 앞에 추가
work_queue.appendleft("긴급 작업 X")
print(f"긴급 작업 추가 후: {list(work_queue)}")

# 앞에서부터 처리
while work_queue:
    task = work_queue.popleft()
    print(f"  처리 완료: {task}")

# === 2. 우선순위 큐: 중요도 기반 처리 ===
print()
print("=" * 40)
print("🏥 우선순위 큐 - 중요도 기반 처리")
print("=" * 40)

task_heap = []
tasks = [
    (3, "이메일 확인"),
    (1, "서버 장애 복구"),
    (2, "고객 문의 응답"),
    (1, "보안 패치 적용"),
]

for priority, name in tasks:
    heapq.heappush(task_heap, (priority, name))
    print(f"  등록: [{priority}] {name}")

print("\n처리 순서:")
while task_heap:
    priority, name = heapq.heappop(task_heap)
    print(f"  ▶ [{priority}] {name}")

# === 3. 회문 검사 (덱 활용) ===
print()
print("=" * 40)
print("🔄 회문 검사")
print("=" * 40)

def is_palindrome(word):
    dq = deque(word)
    while len(dq) > 1:
        if dq.popleft() != dq.pop():
            return False
    return True

test_words = ["토마토", "기러기", "자료구조", "level", "hello"]
for w in test_words:
    result = "✅ 회문" if is_palindrome(w) else "❌ 아님"
    print(f"  '{w}' → {result}")

    실수 1: 리스트를 덱 대신 사용하기 ❌¶

    # ❌ 리스트의 앞쪽 삽입/삭제는 느립니다 (O(n))
my_list = [1, 2, 3]
my_list.insert(0, 0)   # 모든 요소를 한 칸씩 밀어야 함
my_list.pop(0)          # 모든 요소를 한 칸씩 당겨야 함

# ✅ deque를 사용하세요 (O(1))
from collections import deque
dq = deque([1, 2, 3])
dq.appendleft(0)  # 빠름!
dq.popleft()       # 빠름!

    요소가 수천, 수만 개일 때 성능 차이가 극적으로 드러납니다.

    실수 2: heapq에 직접 인덱싱으로 정렬 순서 기대하기 ❌¶

    import heapq

h = []
heapq.heappush(h, 3)
heapq.heappush(h, 1)
heapq.heappush(h, 2)

# ❌ 힙 내부가 [1, 3, 2]일 수 있음 — 완전히 정렬된 게 아닙니다!
print(h)       # [1, 3, 2] ← h[1]이 h[2]보다 클 수 있음
print(h[0])    # 1 ← 최솟값만 보장됨

# ✅ 정렬된 순서로 꺼내려면 반드시 heappop을 사용하세요
while h:
    print(heapq.heappop(h))  # 1, 2, 3 순서 보장

    h[0]이 최솟값이라는 것만 보장됩니다. 나머지 요소의 순서는 보장되지 않습니다!

    실수 3: 최대 힙을 위해 sort를 반복하기 ❌¶

    import heapq

# ❌ 매번 정렬하면 O(n log n) — 비효율적!
data = [5, 3, 8, 1]
data.sort(reverse=True)
biggest = data.pop(0)

# ✅ 음수 트릭으로 최대 힙 구현 — 삽입/삭제 O(log n)
max_heap = []
for x in [5, 3, 8, 1]:
    heapq.heappush(max_heap, -x)
biggest = -heapq.heappop(max_heap)  # 8

    응용 문제¶

    문제 3. 정수 리스트에서 가장 큰 값 3개를 효율적으로 구하는 함수를 heapq로 작성해 보세요.

    💡 힌트: heapq.nlargest(n, iterable) 함수가 있습니다. 또는 음수 트릭을 사용해도 됩니다.

    정답 확인 
    import heapq

def top3(numbers):
    return heapq.nlargest(3, numbers)

print(top3([42, 17, 93, 8, 55, 71]))  # [93, 71, 55]

    심화 문제¶

    문제 4. 카드 게임에서 덱의 앞 카드를 뒤로 보내는 동작을 반복하다가 홀수 번째 동작에서는 카드를 버리는 게임을 구현해 보세요. 카드가 1장 남을 때까지 반복하고 남은 카드를 출력하세요.

    입력: [1, 2, 3, 4, 5, 6, 7] 일 때, 홀수 번째(1,3,5...)에 앞 카드 버리기, 짝수 번째에 앞 카드를 뒤로 보내기

    정답 확인 
    from collections import deque

cards = deque([1, 2, 3, 4, 5, 6, 7])
turn = 1

while len(cards) > 1:
    if turn % 2 == 1:  # 홀수 번째: 버리기
        removed = cards.popleft()
        print(f"버림: {removed}")
    else:              # 짝수 번째: 뒤로 보내기
        cards.append(cards.popleft())
    turn += 1

print(f"남은 카드: {cards[0]}")  # 6
